# Neon Frontier

Компактная процедурная 3D-игра на Rust и Bevy для Windows 11: город, пешее движение, машина, маршрут, жители и розыск. Это оригинальный прототип, а не игра масштаба GTA 6 или готовый AAA-релиз.

## Уже реализовано

- Вид от третьего лица, ходьба, бег, прыжок, камера мышью; персонаж поворачивается по фактическому направлению движения и слегка покачивается.
- WASD-управление машиной, вход и выход при низкой скорости, простые газ, торможение и занос.
- Маршрутная миссия из трёх целей, кредиты, пауза, bloom, русские подсказки и локальное сохранение.
- Процедурные дороги, здания, тротуары, бордюры, переходы, окна, свет и процедурные поверхности.
- 14 машин трафика, 14 жителей и две патрульные машины. Есть базовое торможение перед препятствиями и скольжение вдоль части блокировок.
- Удар по жителям, здоровье NPC, сбивание с ног и уровни розыска. Полиция преследует игрока автомобилями.
- HDR, тонмаппинг, bloom, туман, PBR-материалы и светящиеся детали города.
- В главном меню есть надпись «Сделано FoxVuk и Claude Opus 5.5».

Полноценная анимация шага и бега, устойчивый объезд препятствий свободной полосой, высадка офицеров и стрельба полиции пока не реализованы. Усиленные текстуры ждут прохождения текущего CI и визуальной проверки на Windows 11.

## Управление

- WASD — ходьба; за рулём — газ, тормоз и поворот.
- Shift — бег; Space — прыжок; F — удар.
- Мышь — камера; ЛКМ захватывает курсор; Esc — пауза.
- Enter или ЛКМ — начать; E — сесть в машину рядом или выйти при низкой скорости.
- B — переключить bloom; F5 — сохранить; F9 — загрузить.

## Сборка в Windows 11

Нужны Rust 1.100 или новее, Cargo, MSVC C++ Build Tools с компонентом Desktop development with C++ и Windows SDK. Из каталога проекта:

```powershell
rustup update stable
cargo fmt --all -- --check
cargo test --release
cargo run --release
```

Время завершения текущего run #40 неизвестно: последний статус показывает выполняющийся шаг тестов. Длительность кэширования Cargo сама по себе не является временем компиляции игры.

## Ограничения

Физика уровня GTA 6 остаётся ориентиром, а не обещанием полного паритета. Аппаратный ray tracing и DLSS не реализованы; FPS, температура и VRAM на RTX 3050 не измерялись. Чужие игровые ассеты, музыка и карты не добавлялись.
