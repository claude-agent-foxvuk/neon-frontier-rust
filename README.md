# Neon Frontier

Компактный оригинальный 3D-прототип открытого города на Rust 1.100+ и Bevy 0.20.1 для Windows 11. В проекте есть пешее управление, машина, трафик, жители, розыск, маршрутные задания и меню. Это не игра масштаба GTA 6.

## Возможности в исходниках

- Камера от третьего лица, ходьба, бег, прыжок, разворот персонажа по движению и простая анимация.
- Управляемая машина: газ, тормоз, поворот, занос, вход и выход.
- Процедурный компактный город с дорогами, тротуарами, зданиями, окнами и светом.
- 14 машин трафика, 14 жителей, две патрульные машины, пеший офицер и шесть уровней розыска.
- Маршрутные задания, кредиты и здоровье в HUD.
- PBR, HDR, тонмаппинг, bloom, туман, процедурные поверхности с зерном и бесшовным повтором, цикл дня и ночи.
- Меню: «Новая игра», «Загрузить сохранение», «Кредитс», «Сделано FoxVuk и Claude Opus 5.5».
- Сериализатор save V1 для игрока, машины и большей части состояния города. Время мира и состояние неба пока не сериализуются.

## Управление

- WASD — ходьба; в машине — газ, тормоз и поворот.
- Shift — бег; Space — прыжок; F — удар; E — сесть в машину или выйти при низкой скорости.
- Мышь — камера; Esc — пауза; B — bloom; F5/F9 — сохранить/загрузить в игре.
- В меню — стрелки вверх/вниз и Enter/пробел; пункты выбираются мышью.

## Сборка на Windows 11

Нужны Rust 1.100+, Cargo, MSVC C++ Build Tools и Windows SDK.

```powershell
cargo fmt --all -- --check
cargo test --release
cargo run --release
```

Аппаратные ray tracing и DLSS не реализованы; FPS на RTX 3050 не измерялся. Подробности и оставшиеся задачи — в `MUST_HAVE.md` и `TODO.md`.
