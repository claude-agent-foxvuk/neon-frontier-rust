# Neon Frontier

Компактный процедурный 3D-прототип городской игры на Rust и Bevy для Windows 11. Есть вид от третьего лица, пешее управление, прыжок, машина, городская сетка, маршрут-миссия, трафик, жители, патруль и розыск. Это ранний прототип, не игра масштаба GTA 6 и не готовый AAA-релиз.

## Последняя проверенная сборка

Windows run #33 завершился успешно на исходном коде SHA `0c783f62261dc68a7ad8f718b44cd133e867e8f0`: `cargo fmt --all -- --check`, `cargo test --release`, `cargo build --release` и EXE-артефакт прошли. Артефакт `neon-frontier-windows-x64` весил 28 627 268 байт. Прогон занял 5 мин 4 сек, из них 3 мин 25 сек — кэширование Cargo. Это один измеренный прогон, не гарантия времени следующей сборки.

Фокс поверхностно проверил игру из #33. Его наблюдения: машины трафика застревают друг в друге; столкновение чужой машины может полностью заблокировать управление игроком; машины и полиция проходят сквозь здания и другие автомобили; полицейские остаются в машине и не стреляют; уровни розыска в одну и две звезды почти не отличаются на практике; визуальный стиль с кубической геометрией не устроил. Эти игровые проблемы не считаются исправленными успешным CI.

В текущем исходном коде HUD отдельно описывает одну и две звезды розыска. Это только пояснение к уже существующей шкале скорости патруля, оно не реализует выход офицера из машины, стрельбу, физический объезд или новые столкновения. Для новой правки `src/ui.rs` ещё требуется Windows-проверка. Остальные незакрытые работы перечислены в TODO.md; MUST_HAVE.md описывает то, что уже есть и должно сохраниться.

## Что есть в исходном коде

- Третье лицо, ходьба, бег, прыжок и управление камерой мышью.
- Машина на WASD, вход рядом с ней и выход при малой скорости; физика пока простая.
- Маршрут из трёх целей, кредиты за завершение, локальное сохранение, пауза и русский HUD.
- Процедурно размещённые дороги и 36 зданий; тротуары, бордюры и переходы.
- 14 машин трафика, 14 жителей, две машины патруля, 1 008 светящихся окон, 36 стоек освещения и цветной свет на девяти перекрёстках.
- Удары по жителям, условное здоровье NPC и пять уровней розыска реализованы в коде; качество игрового поведения требует исправлений и ручной проверки.
- PBR-материалы, HDR, тонмаппинг, bloom, туман, уличные огни и светящиеся окна. Процедурных текстур фасадов и надёжного автомобильного ИИ пока нет.

## Управление

- WASD — ходьба; за рулём — газ, тормоз и поворот.
- Shift — бег; Space — прыжок.
- Мышь — камера; ЛКМ захватывает курсор.
- Enter или ЛКМ — начать из меню.
- E — сесть в машину рядом или выйти при малой скорости.
- F — удар по пешеходам.
- Esc — пауза и освобождение мыши; B — переключить bloom.
- F5 — сохранить; F9 — загрузить.

В главном меню сохранена надпись «Сделано FoxVuk и Claude Opus 5.5». Сохранение хранит позицию игрока и машины, прогресс маршрута, кредиты и bloom в `neon_frontier_save.txt`.

## Сборка в Windows 11

Нужны Rust 1.100 или новее, Cargo, MSVC C++ Build Tools с компонентом Desktop development with C++ и Windows SDK. Команды из каталога проекта:

```powershell
rustup update stable
cargo fmt --all -- --check
cargo test --release
cargo run --release
```

GitHub Actions кэширует Cargo и `target`. В #33 кэширование заняло 3 мин 25 сек из общего времени 5 мин 4 сек. Следующая сборка может идти дольше. `Cargo.lock` пока не закоммичен.

## Ограничения

Аппаратный ray tracing и DLSS не реализованы. FPS, температура и VRAM на RTX 3050 не измерялись. Физика уровня GTA 6 — ориентир, не обещание паритета. Текущая геометрия города строится процедурно, но новые процедурные текстуры ещё предстоит добавить. Чужие игровые ассеты, музыка и карты не добавлялись.
