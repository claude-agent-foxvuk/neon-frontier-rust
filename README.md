# Neon Frontier

Оригинальный компактный 3D-прототип городской игры на Rust для Windows 11. Сейчас есть пешее управление, одна управляемая машина, процедурный город, простой трафик, короткий маршрут, стартовое меню и локальное сохранение. Это ранний прототип, не игра масштаба GTA 6 и не готовый AAA-релиз.

## Текущий статус

В присланном Фоксом скриншоте кириллица в HUD отображается квадратами, а город выглядит упрощённым. После этого в код добавлен выбор системного шрифта Segoe UI с запасными Arial и sans-serif, контрастная панель HUD, холодная палитра, металлические детали зданий и мягкий дальний туман. Эти новые изменения ещё не проверены свежей Windows-сборкой или повторным запуском у Фокса.

В журнале запуска старого run #18 Bevy создал окно, Vulkan распознал RTX 3050 Laptop GPU, затем приложение остановилось с `error[B0001]`. Взаимоисключающие ECS-фильтры для машин и жителей добавлены как кандидатное исправление; по старой ошибке нельзя подтвердить, что причиной была именно эта система. Фокс также присылал скриншот уже отрисованного города, поэтому пока неизвестно, при каких условиях запуск остановился и насколько новый шрифт исправит квадраты.

Текущая игровая кодовая версия находится в коммите `8960a2b05a23bf6f9018165157f34bb8351ef7cd`. Последний успешный Windows run #22 проверял более ранний SHA `7fca4c0afd0b61421b6d0b101c1e73e8ce656da5`, до новых изменений шрифта и графики. Свежая проверка текущего кода ещё не запущена.

## Что есть в коде

Процедурная городская сетка с дорогами, разметкой, 36 зданиями разной высоты, 14 машинами простого трафика, 14 пешеходами, четырьмя крышными ориентирами, 36 декоративными фонарями, девятью цветными источниками света и 1 008 светящимися окнами. Игрок может ходить и бегать, сесть в одну машину, ехать и выйти на малой скорости. Короткая миссия ведёт через три точки и выдаёт награду.

Главное меню содержит надпись «Сделано FoxVuk и Claude Opus 5.5». В коде для меню и HUD выбираются Segoe UI, Arial и sans-serif; фактическое отображение кириллицы после этой правки нужно проверить на Windows. F5 сохраняет позицию игрока и машины, прогресс маршрута, кредиты и bloom в `neon_frontier_save.txt` в текущей папке запуска; F9 загружает сохранение.

## Управление

- WASD — ходьба или газ/поворот машины.
- Shift — бег.
- Мышь — камера; ЛКМ захватывает курсор.
- Enter или ЛКМ — начать из меню.
- E — сесть в машину рядом или выйти при малой скорости.
- Esc — пауза и освобождение мыши.
- B — переключить bloom.
- F5 — сохранить; F9 — загрузить.

## Сборка в Windows 11

Нужны Rust 1.100 или новее, Cargo, MSVC C++ Build Tools с компонентом Desktop development with C++ и Windows SDK. В PowerShell из каталога проекта:

```powershell
rustup update stable
cargo fmt --all -- --check
cargo test
cargo run --release
```

Первый запуск Cargo загрузит Bevy и зависимости и может занять время. В workflow заданы `opt-level = 2`, `lto = false`, `codegen-units = 16`; кэшируются `~/.cargo/registry`, `~/.cargo/git` и `target`. Даже успешная компиляция не гарантирует запуск игры. Для тестирования правок шрифта и графики нужен EXE из Windows run, собранного на актуальном SHA.

## Графика, лицензии и ограничения

В коде заданы PBR-материалы, HDR-камера, тонмаппинг, направленный свет с тенями, bloom, светящиеся фасады и уличные огни. Новые материалы, детали, туман и системный шрифт пока не прошли свежую Windows-сборку или визуальную проверку. Аппаратный ray tracing и DLSS не реализованы. Модели, здания, окна, фонари и материалы создаются кодом; чужие игровые ассеты, музыка и карты не добавлялись. Платные модели, API-ключи и платные сервисы разработки не использовались.
