# Neon Frontier

Компактный оригинальный 3D-прототип открытого города на Rust 1.100+ и Bevy 0.20.1 для Windows 11. Есть пешее управление, автомобиль, трафик, жители, розыск, маршрутные цели и меню. Это самостоятельный небольшой прототип, не игра масштаба GTA 6.

## Что уже есть

- Камера от третьего лица; ходьба, бег, прыжок, поворот персонажа, базовая анимация и удар.
- Машина с газом, тормозом, рулением, боковым заносом, посадкой и выходом.
- Процедурный город с дорогами, тротуарами, фасадами, окнами, уличным светом и процедурными поверхностями.
- Трафик, жители, две патрульные машины, шесть уровней розыска и пешие офицеры; жители получают урон и отбрасываются.
- Русский HUD, маршрутные цели, кредиты, здоровье, цикл дня и ночи, PBR, HDR, bloom и туман.
- Сейв остаётся `NEON_FRONTIER_SAVE_V1`; сохраняются данные игрока и расширенное состояние мира.
- `src/physics.rs` содержит OBB/SAT и тесты. OBB применяется к части дорожной логики, контактам трафика с пешеходами и раздвижению пар машин; полная интеграция игрока, трафика, патрулей и зданий остаётся открытой.
- Тест `src/city_life/traffic_regression_tests.rs` проверяет, что уже разделённая OBB-пара машин не перемещается повторно при следующем проходе; результат #97 ещё ожидается.
- Главное меню содержит подпись «Сделано FoxVuk и Claude Opus 5.5».

## Управление

- WASD — ходьба; за рулём — газ, тормоз и поворот.
- Shift — бег; Space — прыжок; F — удар; E — сесть в машину или выйти при низкой скорости.
- Мышь — камера; Esc — пауза; B — bloom; F5/F9 — сохранить/загрузить во время игры.
- В меню — стрелки вверх/вниз, Enter/пробел или щелчок мыши.

## Сборка на Windows 11

Нужны Rust 1.100+, Cargo, MSVC C++ Build Tools и Windows SDK.

```powershell
cargo fmt --all -- --check
cargo test --release --features bevy/debug
cargo build --release --features bevy/debug
cargo run --release
```

Аппаратный ray tracing и DLSS не реализованы; FPS на RTX 3050 не измерен. Актуальные открытые требования — в `TODO.md`, подтверждённые исходниками возможности — в `FEATURES.md`. В первую очередь остаются полная OBB-интеграция, физика машины, полиция уровней 3–6, задания, HUD, ручная проверка EXE и успешный Windows-прогон на текущем `main`. P3 про свидетелей, поток, пляж и воду отложен.
