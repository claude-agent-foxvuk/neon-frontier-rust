# Neon Frontier

Компактный оригинальный 3D-прототип открытого города на Rust 1.100+ и Bevy 0.20.1 для Windows 11. Есть пешее управление, автомобиль, трафик, жители, розыск, маршрутные цели и меню. Это не игра масштаба GTA 6.

## Состояние проекта

Тест `sun_peaks_at_noon_and_bottoms_out_at_midnight` исправлен: `sun_height(1.5)` сравнивается с эквивалентным `sun_height(0.5)`; он проходил в логах #57, #58 и #60. Машина игрока больше не растягивает дочерние детали кузова, а мигалки дочерние для патрульной машины и включаются при ненулевом розыске. Эти визуальные изменения ещё надо проверить вручную на Windows.

Сейв остаётся `NEON_FRONTIER_SAVE_V1`: записываются время суток, здоровье, розыск, движение игрока, машина, камера, трафик, жители, патрули, пешие офицеры и таймеры. Старый V1 без времени читается со значением по умолчанию. Проверяется количество сущностей до восстановления. Unit-тесты кодека и `tests/runtime_world.rs` покрывают round-trip; свежие runtime-assertions проверяют дополнительные параметры машин и жителей. Windows-проверка этих assertions идёт в #64.

В `src/physics.rs` есть OBB/SAT, swept movement с регрессионными тестами и `resolve_body_pairs` с равным раздвижением динамических тел. Unit-тесты проверяют пары авто-авто, авто-пешеход и пешеход-пешеход. Парный helper ещё не подключён к ECS-логике игры. В `src/city_life.rs` ориентированные кузова уже используются для части объездов и контактов с пешеходами; полная игровая интеграция OBB, интеграционные тесты и улучшение физики автомобиля остаются в `TODO.md`.

## Возможности в исходниках

- Камера от третьего лица; ходьба, бег, прыжок, разворот и простая анимация персонажа.
- Автомобиль: газ, тормоз, поворот, занос, вход и выход при малой скорости; кузов, кабина, колёса и фары.
- Процедурный город: дороги, тротуары, фасады, окна, уличные огни, PBR, HDR, bloom и туман.
- 14 машин трафика, 14 жителей, две патрульные машины, пешие офицеры и шесть уровней розыска.
- Маршрутные цели, кредиты, здоровье и HUD на русском.
- Мигалки патруля, процедурные текстуры и сохранения V1.
- Главное меню: «Новая игра», «Загрузить сохранение», «Кредитс», «Сделано FoxVuk и Claude Opus 5.5».

## Управление

- WASD — ходьба; в машине — газ, тормоз и поворот.
- Shift — бег; Space — прыжок; F — удар; E — сесть в машину или выйти при низкой скорости.
- Мышь — камера; Esc — пауза; B — bloom; F5/F9 — сохранить/загрузить в игре.
- В меню — стрелки вверх/вниз и Enter/пробел; пункты выбираются мышью.

## Сборка на Windows 11

Нужны Rust 1.100+, Cargo, MSVC C++ Build Tools и Windows SDK.

```powershell
cargo fmt --all -- --check
cargo test --release
cargo run --release
```

Аппаратные ray tracing и DLSS не реализованы; FPS на RTX 3050 не измерялся. Актуальный список незакрытых требований находится в `TODO.md`, список реализованных возможностей — в `MUST_HAVE.md`.
