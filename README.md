## Текущее состояние и блокер

Проверка GitHub на 2026-11-23: репозиторий приватный, ветка `main`, GitHub Actions включён, но workflow и Actions secrets пока отсутствуют. Issue #1 с техническим заданием открыт. Подключённый GitHub API не смог показать список установок приложений, поэтому наличие официального Claude GitHub App здесь не подтверждено.

Для Claude Code через `@claude` нужны рабочий workflow, установленное приложение и авторизация Anthropic. Фокс сообщил, что у него нет денег на Claude и нет API-ключей; платную авторизацию и новые расходы не используем. Сейчас проверяется только возможность уже включённого coding agent в существующем GitHub-аккаунте. Пока такой путь без новых расходов не подтверждён, разработка не запущена.

Аппаратный запуск и графика на RTX 3050 ещё не проверялись. Не заявляем FPS, DLSS или ray tracing.
