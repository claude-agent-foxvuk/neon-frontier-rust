# Neon Frontier

Компактная процедурная 3D-игра на Rust 1.100+ и Bevy 0.20.1 для Windows 11: небольшой город, пешее движение, машина, маршрут, жители и розыск. Это оригинальный прототип, не игра масштаба GTA 6.

## Статус проверки

Последний коммит игрового кода `d2e85ea` восстанавливает из V1-сохранения движение игрока и камеры. Теперь сохраняются положение и высота игрока, прыжок, анимационные флаги, руление и боковая скорость машины, режим управления и ориентация камеры. Полный снимок фаз жителей, объезда и патрулей, безопасная проверка числа сущностей и runtime round-trip всё ещё требуют работы.

Последняя зелёная Windows-проверка — run #41 на `97833d0b89cc7b38df0e5ac498f06274b39419bb`; она загрузила `neon-frontier-windows-x64` размером 28 641 348 байт, но это старый EXE. Runs #42 и #43 завершились ошибкой форматирования. После #43 новой проверки не было, актуальный EXE не подтверждён.

Новый Windows workflow запускать только после закрытия всего игрового TODO. Затем проверять точный актуальный `main` и подтверждать `neon-frontier-windows-x64`.

## Уже есть в исходниках
- Вид от третьего лица, ходьба, бег, прыжок, разворот по движению, bob и наклон.
- Машина игрока с газом, тормозом, поворотом, простым заносом, посадкой и выходом.
- Процедурный город, окна, уличный свет, PBR, HDR, bloom и туман.
- 14 машин трафика и 14 жителей; учитываются игрок, оставленная машина и патрули; трафик пробует боковой объезд.
- Два полицейских патруля; от двух звёзд пеший офицер преследует игрока, показывает вспышку и наносит урон при прямой видимости.
- V1-сейв восстанавливает состояние игрока, камеры и машины, а также базовые данные маршрута, жителей, трафика, полиции и розыска. Точное восстановление полного мира остаётся открытым; V1 не менять.
- В главном меню есть клавиатурный выбор и обработка кликов мышью для «Новая игра», «Загрузить сохранение» и «Кредитс». Свежая сборка ещё не проверила переходы меню и блокировку F5/F9 в меню.
- Устаревшее «Маршрут выполнен» фильтруется в HUD.

## Управление
- WASD — ходьба; в машине — газ, тормоз и поворот.
- Shift — бег; Space — прыжок; F — удар; E — войти в машину или выйти при низкой скорости.
- Мышь — камера; Esc — пауза; B — bloom; F5/F9 — сейв/загрузка внутри игры.
- В меню — стрелки вверх/вниз и Enter/пробел; также можно щёлкнуть мышью по строке пункта.

## Сборка для Windows 11
Нужны Rust 1.100+, Cargo, MSVC C++ Build Tools и Windows SDK.

```powershell
cargo fmt --all -- --check
cargo test --release
cargo run --release
```

Открытые требования и приоритеты — в `TODO.md`, функции, которые нужно сохранить, — в `MUST_HAVE.md`. Аппаратные ray tracing и DLSS не реализованы; производительность на RTX 3050 отдельно не измерялась.
