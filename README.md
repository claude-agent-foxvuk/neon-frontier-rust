# Neon Frontier

Компактный оригинальный 3D-прототип открытого города на Rust 1.100+ и Bevy 0.20.1 для Windows 11. В игре есть пешее управление, автомобиль, трафик, жители, розыск, маршрутные цели и меню. Это самостоятельный небольшой прототип, не игра масштаба GTA 6.

## Что есть в исходниках

- Камера от третьего лица; ходьба, бег, прыжок, поворот персонажа, базовая анимация и удар.
- Машина с газом, тормозом, рулением, заносом, посадкой и выходом; модель включает кузов, кабину, колёса и фары.
- Процедурный город с дорогами, тротуарами, фасадами, окнами, уличным светом и процедурными поверхностями.
- Трафик, жители, две патрульные машины, шесть уровней розыска и пешие офицеры; у жителей есть урон и отбрасывание.
- Русский HUD, маршрутные цели, кредиты, здоровье, цикл дня и ночи, PBR, HDR, bloom и туман.
- Сейв остаётся `NEON_FRONTIER_SAVE_V1`; сериализуются время суток, состояние игрока и мира. Есть проверки формата, старого V1 и runtime-восстановления.
- OBB/SAT и раздвижение пар реализованы как физические helpers и покрыты unit-тестами. В игровой ECS-логике SAT подключён только к части взаимодействий; полная интеграция ещё открыта.
- Главное меню содержит «Сделано FoxVuk и Claude Opus 5.5».

## Управление

- WASD — ходьба; за рулём — газ, тормоз и поворот.
- Shift — бег; Space — прыжок; F — удар; E — сесть в машину или выйти при низкой скорости.
- Мышь — камера; Esc — пауза; B — bloom; F5/F9 — сохранить/загрузить во время игры.
- В меню — стрелки вверх/вниз, Enter/пробел или щелчок мыши.

## Сборка на Windows 11

Нужны Rust 1.100+, Cargo, MSVC C++ Build Tools и Windows SDK.

```powershell
cargo fmt --all -- --check
cargo test --release --features bevy/debug
cargo build --release --features bevy/debug
cargo run --release
```

В workflow тесты сохраняют `--release`, чтобы release-сборка могла повторно использовать уже скомпилированные артефакты. В #66 тесты заняли 12:57, последующая сборка — 1 секунду. Аппаратный ray tracing и DLSS не реализованы; FPS на RTX 3050 не измерен.
