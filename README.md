# Neon Frontier

Компактная оригинальная 3D-игра с открытым городом на Rust 1.100+ и Bevy 0.20.1 для Windows 11. Это самостоятельный прототип с вождением и действием, не игра масштаба GTA 6.

## Уже есть
- Пешее управление, бег, прыжок, удар, здоровье и камера от третьего лица.
- Управляемая машина с инерцией, торможением, рулением и боковым скольжением; трафик и жители.
- Процедурный компактный город с дорогами, фасадами, окнами и освещением.
- Шесть уровней розыска, две патрульные машины, пешие офицеры и мигалки. На уровнях 3–6 пешие офицеры быстрее и опаснее, ищут последнюю известную позицию, а шкала HUD показывает отдельное описание ответа полиции для каждого уровня.
- Русский HUD: десять сегментов здоровья, шесть звёзд розыска и десятисегментный прогресс до смены маршрута каждые 300 кредитов.
- Маршрутные цели, кредиты, цикл дня и ночи, PBR, HDR, bloom и туман.
- OBB/SAT для контактов игрока, машин, жителей, патрулей и зданий; безопасное раздвижение машин и объезд припаркованной машины по свободной полосе.
- Сохранение `NEON_FRONTIER_SAVE_V1`; главное меню с подписью «Сделано FoxVuk и Claude Opus 5.5».
- Симуляция жителей, трафика и полиции остановлена в главном меню. Заморозка часов и визуальных обновлений через `update_world` пока открыта.

## Управление
- WASD — ходьба; Shift — бег; Space — прыжок; F — удар.
- За рулём WASD — газ, тормоз и поворот; E — сесть или выйти при низкой скорости.
- Мышь — камера; Esc — пауза; B — bloom; F5/F9 — сохранить/загрузить во время игры.
- В меню — стрелки вверх/вниз, Enter/пробел или щелчок мыши.

## Сборка
На Windows 11 нужны Rust 1.100+, Cargo, MSVC C++ Build Tools и Windows SDK.

```powershell
cargo fmt --all -- --check
cargo test --release --features bevy/debug
cargo build --release --features bevy/debug
cargo run --release
```

Аппаратный ray tracing и DLSS не реализованы; FPS на RTX 3050 ещё не измерен.
