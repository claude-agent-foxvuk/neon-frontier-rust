# Neon Frontier

Компактная оригинальная 3D-игра с открытым городом на Rust 1.100+ и Bevy 0.20.1 для Windows 11. Это самостоятельная игра про вождение и действие, не проект масштаба GTA 6.

## Реализованные возможности
- Пешее управление, бег, прыжок, удар, здоровье и камера от третьего лица.
- Управляемая машина с разгоном, торможением, накатом, постепенным рулением и боковым скольжением. При движении вперёд D поворачивает вправо, A — влево; нос машины направлен по движению.
- Процедурный город с дорогами, фасадами, окнами, уличным освещением и светящимися элементами.
- Трафик и жители с динамическими OBB-коллизиями; машины ищут свободную полосу и тормозят перед препятствиями.
- Четыре озеленённые площадки у центрального перекрёстка с деревьями и скамьями; их OBB-препятствия учитываются, дорожки остаются проходимыми.
- Шесть уровней розыска, патрули, резервные машины, усиление пешеходных офицеров и три динамических городских события.
- Русский HUD, маршрутные цели, кредиты, цикл дня и ночи, PBR, HDR, bloom и туман.
- Сохранение `NEON_FRONTIER_SAVE_V1` с состоянием игрока, машины, маршрута и мира.

## Управление
- WASD — ходьба; Shift — бег; Space — прыжок; F — удар.
- За рулём W — газ, S — тормоз, A — влево, D — вправо; E — сесть или выйти при низкой скорости.
- Мышь — камера; Esc — пауза; B — bloom; F2 — режим графики; F5/F9 — сохранить/загрузить во время игры.
- В меню — стрелки вверх/вниз, Enter/пробел или щелчок мыши.

## Сборка
На Windows 11 нужны Rust 1.100+, Cargo, MSVC C++ Build Tools и Windows SDK.

```powershell
cargo fmt --all -- --check
cargo test --release --features bevy/debug
cargo build --release --features bevy/debug
cargo run --release
```

Аппаратный ray tracing и DLSS не реализованы. Влияние режима производительности и FPS на RTX 3050 ещё не измерены.
