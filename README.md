# Neon Frontier

Компактная оригинальная 3D-игра с открытым городом на Rust 1.100+ и Bevy 0.20.1 для Windows 11. Это самостоятельный прототип про вождение и действие, а не проект масштаба GTA 6.

## Уже есть в исходниках
- Пешее управление, бег, прыжок, удар, здоровье и камера от третьего лица.
- Управляемая машина с инерцией, торможением, рулением и боковым скольжением. При движении вперёд D поворачивает вправо, A — влево; нос модели выровнен по движению.
- Трафик и жители с динамическими OBB-коллизиями. Машины выбирают свободную полосу, учитывают ширину дороги и останавливаются перед препятствиями.
- Процедурный компактный город с дорогами, фасадами, окнами, освещением, светящимися полосами на крышах и цветными панелями фасадов.
- Четыре озеленённые площадки у центрального перекрёстка с деревьями и скамьями. Их OBB-коллайдеры учитываются игроком, дорожки остаются проходимыми.
- Шесть уровней розыска, патрули и резервные полицейские машины; на высоких уровнях меняется тактика, скорость пеших офицеров и их урон.
- Три динамических городских события: скрыться от полиции, чисто проехать у трафика и продержать высокую скорость рядом с машинами. События дают здоровье или кредиты.
- Русский HUD, маршрутные цели, кредиты, цикл дня и ночи, PBR, HDR, bloom и туман.
- Сохранение `NEON_FRONTIER_SAVE_V1` с состоянием игрока, машины, маршрута, мира, полиции и жителей.

## Управление
- WASD — ходьба; Shift — бег; Space — прыжок; F — удар.
- За рулём W — газ, S — тормоз, A — влево, D — вправо; E — сесть или выйти при низкой скорости.
- Мышь — камера; Esc — пауза; B — bloom; F2 — режим графики; F5/F9 — сохранить/загрузить во время игры.
- В меню — стрелки вверх/вниз, Enter/пробел или щелчок мыши.

## Сборка
На Windows 11 нужны Rust 1.100+, Cargo, MSVC C++ Build Tools и Windows SDK.

```powershell
cargo fmt --all -- --check
cargo test --release --features bevy/debug
cargo build --release --features bevy/debug
cargo run --release
```

Аппаратный ray tracing и DLSS не реализованы. Влияние режима производительности и FPS на RTX 3050 ещё не измерены.
