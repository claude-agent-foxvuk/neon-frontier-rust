# Neon Frontier

Оригинальный компактный 3D-прототип городской игры на Rust для Windows 11. Есть пешее управление, одна управляемая машина, процедурный город, простой трафик и короткий маршрут-миссия. Это не игра масштаба GTA 6 и не готовый AAA-релиз.

## Текущий статус

Фокс запускал старый EXE из run #18 на Windows 11 Pro, ASUS TUF Gaming F16 с RTX 3050 Laptop GPU 6 ГБ. Vulkan распознал видеокарту и Bevy создал окно, после чего приложение упало с `error[B0001]`. Из этого запуска не следует, что игровой процесс или меню работали.

Для запросов машин и пешеходов добавлены взаимоисключающие ECS-фильтры как кандидат на исправление `B0001`. Windows run #20 успешно прошёл форматирование, тесты, release-сборку и загрузил EXE для кода на SHA `1e9dfece9d7e32bce93bc644936495ad3b1d7d8d`. Это подтверждает сборку, но не запуск исправленного EXE на ноутбуке Фокса.

После run #20 сохранения вынесены из `src/main.rs` в отдельный `src/save.rs`; кодовый рефакторинг сейчас на SHA `095e674ba095dd5e3b021d92143e6f74fd5e060a`. Этот свежий код ещё не проходил Windows CI. Следующая проверка должна собирать именно его, а не повторять run #20.

## Что есть в коде

Процедурная городская сетка с дорогами, разметкой, 36 зданиями разной высоты, 14 машинами простого трафика, 14 пешеходами, четырьмя крышными ориентирами, 36 декоративными фонарями, девятью цветными источниками света и 1 008 светящимися окнами. Игрок может идти пешком, бежать, сесть в одну машину, ехать и выйти на малой скорости. Короткая миссия ведёт через три точки и выдаёт награду.

Главное меню содержит надпись «Сделано FoxVuk и Claude Opus 5.5». F5 сохраняет позицию игрока и машины, прогресс маршрута, кредиты и bloom в `neon_frontier_save.txt` в текущей папке запуска; F9 загружает сохранение. Текущий код вынес формат сохранения и файловый ввод-вывод в `src/save.rs`.

## Управление

- WASD — ходьба или газ/поворот машины.
- Shift — бег.
- Мышь — камера; ЛКМ захватывает курсор.
- E — сесть в машину рядом или выйти при малой скорости.
- Esc — пауза и освобождение мыши.
- B — переключить bloom.
- F5 — сохранить.
- F9 — загрузить.

## Сборка в Windows 11

Нужны Rust 1.100 или новее, Cargo, MSVC C++ Build Tools с компонентом Desktop development with C++ и Windows SDK. В PowerShell из каталога проекта:

```powershell
rustup update stable
cargo fmt --all -- --check
cargo test
cargo run --release
```

Первый запуск Cargo загружает Bevy и зависимости и может занять время. В workflow заданы `opt-level = 2`, `lto = false`, `codegen-units = 16`; кэшируются `~/.cargo/registry`, `~/.cargo/git` и `target`. Даже успешная компиляция не гарантирует запуск игры: предыдущий EXE завершился с `B0001` на устройстве Фокса. Перед тестом нужно дождаться CI для актуального SHA и скачать его артефакт из соответствующего Windows run.

## Графика и ограничения

В коде заданы PBR-материалы, HDR-камера, тонмаппинг, направленный свет с тенями, bloom, светящиеся фасады и уличные огни. В присланном логе запуска старого EXE Vulkan распознал RTX 3050 Laptop GPU 6 ГБ, затем Bevy упал до игрового процесса. FPS, температура и VRAM не измерялись; визуальная оценка не проведена. Аппаратный ray tracing и DLSS не реализованы.

Модели, здания, окна, фонари и материалы создаются кодом. Сторонние игровые ассеты, музыка и чужая карта не добавлялись. Платные модели, API-ключи и платные сервисы разработки не использовались.
