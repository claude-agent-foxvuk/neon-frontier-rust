# Neon Frontier

Оригинальный компактный 3D-прототип городской игры на Rust для Windows 11. В проекте есть пешее управление, прыжок, одна управляемая машина, процедурный город, простой трафик, короткий маршрут, стартовое меню и локальное сохранение. Это ранний прототип, не игра масштаба GTA 6 и не готовый AAA-релиз.

## Состав игры сейчас

Процедурная городская сетка с дорогами и разметкой, 36 зданиями, простыми 14 машинами трафика и 14 пешеходами, четырьмя крышными ориентирами, 36 декоративными фонарями, девятью цветными источниками света и 1 008 светящимися окнами. Персонаж ходит, бегает и прыгает; можно сесть в одну машину, ехать и выйти на малой скорости. Короткая миссия ведёт через три точки. Маркер миссии плавно меняет размер и яркость.

В меню указано «Сделано FoxVuk и Claude Opus 5.5». F5 сохраняет позицию игрока и машины, прогресс маршрута, кредиты и bloom в `neon_frontier_save.txt` в папке запуска; F9 загружает сохранение.

## Управление

- WASD — ходьба или газ/поворот машины.
- Shift — бег.
- Space — прыжок.
- Мышь — камера; ЛКМ захватывает курсор.
- Enter или ЛКМ — начать из меню.
- E — сесть в машину рядом или выйти при малой скорости.
- Esc — пауза и освобождение мыши.
- B — переключить bloom.
- F5 — сохранить; F9 — загрузить.

## Сборка в Windows 11

Нужны Rust 1.100 или новее, Cargo, MSVC C++ Build Tools с компонентом Desktop development with C++ и Windows SDK. В PowerShell из каталога проекта:

```powershell
rustup update stable
cargo fmt --all -- --check
cargo test --release
cargo run --release
```

Первый запуск Cargo скачивает Bevy и зависимости и может быть долгим. GitHub Actions кэширует `~/.cargo/registry`, `~/.cargo/git` и `target`; успешный run #27 с попаданием в кэш занял 3 мин 55 сек, включая около 2 мин 30 сек на восстановление примерно 2.63 GB. Холодная сборка может занять заметно дольше. Lock-файл пока отсутствует.

## Графика, лицензии и ограничения

В коде заданы PBR-материалы, HDR-камера, тонмаппинг, направленный свет с тенями, bloom, светящиеся фасады и уличные огни. Палитра, детали зданий, туман, пульсация маркера и шрифт требуют визуальной проверки свежего EXE. Аппаратный ray tracing и DLSS не реализованы; FPS, температура и VRAM на RTX 3050 не измерялись. Геометрия и материалы создаются процедурно; чужие игровые ассеты, музыка и карты не добавлялись. Платные модели, API-ключи и платные сервисы разработки не использовались.

Физика уровня GTA 6 — пожелание-ориентир, не обещание паритета. Игра остаётся компактным ранним прототипом.
