# Neon Frontier

Ранняя версия оригинальной игры с городом на Rust для Windows 11. Это пока не готовая игра: исходный код добавлен, но сборка и запуск ещё не проверены.

## Прогресс

Проценты обозначают долю перечисленных этапов в каждом направлении, а не готовность всей игры. Завершённый этап означает наличие указанных файлов или проверенный результат.

- Подготовка: [####################] 100% — приватный репозиторий и описание задачи есть.
- Игровая основа: [#####---------------] 25% — исходный код добавлен; сборка, запуск и проверка управления остаются впереди.
- Город и миссии: [#####---------------] 25% — в коде описаны город, машина, столкновения и маршрут; проверка, расширение и наполнение остаются впереди.
- Графика: [#####---------------] 25% — в коде описаны материалы, свет, тени и bloom; сборка, визуальная проверка и настройка для RTX 3050 остаются впереди.
- Тестирование: [#####---------------] 25% — два теста столкновений написаны; выполнение тестов, сборка Windows и проверка запуска остаются впереди.

## Что сейчас в коде

Процедурные улицы и здания из простых фигур, персонаж, одна машина, точки маршрута с наградой, камера и простая проверка столкновений. Есть заготовка HUD, паузы и переключения bloom. Всё это пока не проверено запуском. Нет трафика, пешеходов, сохранений, настроек качества и законченных миссий. Графика и масштаб пока далеки от GTA 6.

## Управление, которое предстоит проверить

- WASD — движение или управление машиной.
- Shift — бег; E рядом с машиной — сесть или выйти на малой скорости.
- Esc — пауза; B — включить или выключить bloom.

## Сборка для Windows 11

Понадобятся Rust 1.100 или новее, Cargo, MSVC и Windows SDK. В Visual Studio Build Tools выбери компонент Desktop development with C++. В папке проекта команды:

```powershell
rustup update stable
cargo test
cargo run --release
```

В GitHub Actions идёт первая проверка Windows-сборки и тестов; результат пока неизвестен. Первая сборка скачает зависимости и может занять время. Исполняемый файл и готовый архив пока отсутствуют.

## Ограничения

На RTX 3050 игра ещё не запускалась, поэтому производительность, расход видеопамяти и внешний вид не подтверждены. Аппаратный ray tracing и DLSS не реализованы. Платный Claude и API-ключи для текущей работы не используются. Статус будем обновлять по проверенным изменениям.
