# Neon Frontier

Оригинальный компактный 3D-прототип городской игры на Rust для Windows 11. Сейчас есть пешее управление, прыжок, одна управляемая машина, процедурный город, простой трафик, короткий маршрут, стартовое меню и локальное сохранение. Это ранний прототип, не игра масштаба GTA 6 и не готовый AAA-релиз.

## Длительность Windows-сборки

Run #25 был первым холодным успешным запуском после крупных изменений: тесты заняли 43 мин 20 сек, затем отдельный release build — 30 мин 28 сек. До исправления workflow `cargo test` и `cargo build --release` работали в разных профилях, поэтому зависимости компилировались повторно.

В run #26 кэш попал: GitHub восстановил 2 634 565 747 байт; скачивание и распаковка заняли около 2 мин 53 сек. Затем тесты быстро остановились из-за отсутствующего `Cargo.lock` и флага `--locked`. Это короткое падение не измеряет длительность исправленной сборки.

Теперь тесты и приложение используют release-профиль (`cargo test --release` и `cargo build --release`), чтобы иметь возможность повторно использовать release-зависимости. Run #27 ещё не проверил ни cache restore, ни фактическую продолжительность новой конфигурации. Разумное ожидание: при попадании в кэш восстановление может занять несколько минут; точное время тестов и сборки пока неизвестно. Workflow имеет timeout 240 минут — это предел, не ETA. В проекте пока нет закоммиченного `Cargo.lock`, поэтому Cargo разрешает зависимости при сборке; стабильность состава транзитивных зависимостей отдельно не закреплена.

## Что есть в коде

Процедурная городская сетка с дорогами и разметкой, 36 зданиями разной высоты, 14 машинами простого трафика, 14 пешеходами, четырьмя крышными ориентирами, 36 декоративными фонарями, девятью цветными источниками света и 1 008 светящимися окнами. Игрок может ходить и бегать, прыгать клавишей Space, сесть в одну машину, ехать и выйти на малой скорости. Короткая миссия ведёт через три точки и выдаёт награду. Маркер миссии плавно меняет размер и яркость.

Главное меню содержит «Сделано FoxVuk и Claude Opus 5.5». F5 сохраняет позицию игрока и машины, прогресс маршрута, кредиты и bloom в `neon_frontier_save.txt` в папке запуска; F9 загружает сохранение.

## Управление

- WASD — ходьба или газ/поворот машины.
- Shift — бег.
- Space — прыжок.
- Мышь — камера; ЛКМ захватывает курсор.
- Enter или ЛКМ — начать из меню.
- E — сесть в машину рядом или выйти при малой скорости.
- Esc — пауза и освобождение мыши.
- B — переключить bloom.
- F5 — сохранить; F9 — загрузить.

## Сборка в Windows 11

Нужны Rust 1.100 или новее, Cargo, MSVC C++ Build Tools с компонентом Desktop development with C++ и Windows SDK. В PowerShell из каталога проекта:

```powershell
rustup update stable
cargo fmt --all -- --check
cargo test --release
cargo run --release
```

Первый запуск Cargo загружает Bevy и зависимости и может занять время. Workflow кэширует `~/.cargo/registry`, `~/.cargo/git` и `target`; после последней правки тесты и release-сборка используют один профиль, но сокращение времени ещё не измерено. Для воспроизводимой сборки нужно отдельно решить вопрос фиксации `Cargo.lock`.

## Графика, лицензии и ограничения

В коде заданы PBR-материалы, HDR-камера, тонмаппинг, направленный свет с тенями, bloom, светящиеся фасады и уличные огни. Паллировка, детали, туман, пульсация маркера и системный шрифт пока не прошли визуальную проверку в свежей игре. Аппаратный ray tracing и DLSS не реализованы. Модели, здания, окна, фонари и материалы создаются кодом; чужие игровые ассеты, музыка и карты не добавлялись. Платные модели, API-ключи и платные сервисы разработки не использовались.
