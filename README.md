# Neon Frontier

Компактный оригинальный 3D-прототип с открытым городом на Rust 1.100+ и Bevy 0.20.1 для Windows 11. Здесь есть пешее управление, машина, трафик, жители, розыск, миссии-маршрут и меню. Это не игра масштаба GTA 6.

## Что уже реализовано в коде

- Камера от третьего лица, ходьба, бег, прыжок, поворот персонажа по движению, bob и наклон.
- Игровая машина с посадкой и выходом, рулением, ускорением, торможением и заносом; есть стеклянная кабина, колёса и фары.
- Процедурный компактный город, дороги, тротуары, окна, огни, PBR-материалы, HDR, bloom и туман.
- 14 машин трафика, 14 жителей, две патрульные машины и шесть уровней розыска. На уровнях от двух звёзд появляется пеший офицер.
- Упрощённая система маршрутов, здоровье в HUD, стартовое меню и сохранение мира в формате V1.
- Меню содержит пункты «Новая игра», «Загрузить сохранение», «Кредитс» и надпись «Сделано FoxVuk и Claude Opus 5.5».

## Управление

- WASD — ходьба; в машине — газ, тормоз и поворот.
- Shift — бег; Space — прыжок; F — удар; E — сесть в машину или выйти при низкой скорости.
- Мышь — камера; Esc — пауза; B — bloom; F5/F9 — сохранить/загрузить внутри игры.
- В меню — стрелки вверх/вниз и Enter/пробел; пункты также выбираются мышью.

## Сборка на Windows 11

Нужны Rust 1.100+, Cargo, MSVC C++ Build Tools и Windows SDK.

```powershell
cargo fmt --all -- --check
cargo test --release
cargo run --release
```

Аппаратные ray tracing и DLSS не реализованы; FPS на RTX 3050 не измерялся. Список того, что ещё предстоит сделать, остаётся открытым в `TODO.md`.
