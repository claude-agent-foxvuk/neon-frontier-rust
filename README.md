# Neon Frontier

Оригинальный 3D-прототип городской игры на Rust для Windows 11. Это небольшой ранний прототип, а не игра масштаба GTA 6 и не готовый релиз.

## Прогресс по направлениям

Проценты оценивают объём реализованной части, а не качество или общую готовность игры. Наличие кода само по себе не подтверждает, что функция работает на компьютере. Результаты проверок отмечены отдельно.

## Что реализовано

Сцена процедурно создаёт дороги, разметку и здания разной высоты. Игрок может ходить пешком, сесть в машину, ездить и выйти при небольшой скорости. Есть базовые столкновения, третьеличная камера и маршрут из трёх точек с наградой. Дополнительный модуль создаёт 14 движущихся машин, 14 пешеходов и четыре светящихся ориентира. Тесты логики движения и ориентации прошли в Windows CI; сами игровые системы ещё не проверены запуском.

F5 сохраняет состояние игрока, машины, маршрута, кредитов и bloom в `neon_frontier_save.txt` в текущей папке запуска; F9 загружает его. Тесты формата сохранения прошли, функция ещё не проверялась в запущенной игре.

Это ранний прототип. В нём нет боевой системы, разнообразных заданий, проработанных районов, сложного трафика и полноценного меню настроек.

## Управление

- WASD — ходьба или газ/поворот машины.
- Shift — бег.
- E — сесть в машину рядом или выйти при малой скорости.
- Esc — пауза.
- B — переключить bloom.
- F5 — сохранить.
- F9 — загрузить.

Управление заложено в коде, но ещё не проверялось в запущенной сборке.

## Сборка в Windows 11

Нужны Rust 1.100 или новее, Cargo, MSVC C++ Build Tools с компонентом Desktop development with C++ и Windows SDK. Из папки проекта в PowerShell:

```powershell
rustup update stable
cargo test
cargo run --release
```

Первый запуск Cargo скачает Bevy и зависимости и может занять время. Windows workflow проверяет форматирование и тесты, собирает release-версию и загружает артефакт `neon-frontier-windows-x64` на 30 дней. Run #8 успешно прошёл все шаги на Windows runner для коммита `489231523ab33979d33c961f4a9577fa939cd045`: форматирование, тесты, release-сборку и загрузку `.exe`. На момент проверки артефакт доступен по run #8; он истекает 2026-12-23 19:14 UTC.

Чтобы собрать локально, сначала установи Rust 1.100 или новее и MSVC Build Tools, затем выполни `cargo run --release`. Автоматическая CI-сборка использует `opt-level = 2`, `lto = false`, `codegen-units = 16`, кэширует `~/.cargo/registry`, `~/.cargo/git` и `target`, а максимальная длительность job — 240 минут. Предыдущая попытка до этих настроек была отменена на прежнем лимите 110 минут; новый профиль прошёл полный Windows build в run #8.

## Графика и ограничения

В коде заданы PBR-материалы, HDR-камера, тонмаппинг, направленный свет с тенями и bloom. Настройки и производительность не проверялись на реальной RTX 3050 Laptop GPU с 6 ГБ видеопамяти. Аппаратный ray tracing и DLSS не реализованы.

Модели и материалы генерируются кодом. Сторонние игровые ассеты, музыка и карта не добавлялись. Платные модели, API-ключи и платные сервисы разработки не используются.
