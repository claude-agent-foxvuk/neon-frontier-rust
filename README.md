# Neon Frontier

Оригинальный 3D-прототип городской игры на Rust для Windows 11. Это компактная ранняя версия с пешим перемещением, машиной, процедурным городом, простым трафиком и коротким маршрутом-миссией. Это не игра масштаба GTA 6 и не готовый AAA-релиз.

## Что уже есть

Сцена процедурно создаёт сетку дорог, разметку и здания разной высоты. Можно ходить пешком, сесть в одну машину, ездить и выйти при небольшой скорости. Есть базовые столкновения, камера от третьего лица с управлением мышью, маршрут из трёх точек с наградой, 14 машин простого трафика, 14 пешеходов, четыре крышных ориентира и 36 декоративных неоновых уличных фонарей. ## Управление

- WASD — ходьба или газ/поворот машины.
- Shift — бег.
- Мышь — камера; первый щелчок ЛКМ захватывает курсор.
- E — сесть в машину рядом или выйти при малой скорости.
- Esc — пауза и освобождение мыши.
- B — переключить bloom.
- F5 — сохранить.
- F9 — загрузить.

Управление описывает код текущей версии; проверка ввода и камеры в запущенной игре ещё не проводилась.

## Сборка в Windows 11

Нужны Rust 1.100 или новее, Cargo, MSVC C++ Build Tools с компонентом Desktop development with C++ и Windows SDK. В PowerShell из папки проекта:

```powershell
rustup update stable
cargo test
cargo run --release
```

Первый запуск Cargo загрузит Bevy и зависимости и может занять время. CI проверяет форматирование, тесты, release-сборку и публикует артефакт `neon-frontier-windows-x64` на 30 дней. Run #12 успешно прошёл все шаги на коммите `1ec426c47b8c744e545709af743d092bd44817e4`. Чтобы получить архив, открой GitHub Actions в приватном репозитории, выбери успешный run #12 «Windows build check» и скачай артефакт. Внутри находится `neon-frontier.exe`; это не установщик.

Для локальной сборки установи Rust 1.100+ и MSVC Build Tools, затем выполни `cargo run --release`. Windows CI использует `opt-level = 2`, `lto = false`, `codegen-units = 16`, кэширует `~/.cargo/registry`, `~/.cargo/git` и `target`, а предел job равен 240 минутам.

## Графика и ограничения

В коде заданы PBR-материалы, HDR-камера, тонмаппинг, направленный свет с тенями и bloom. Производительность и качество не измерялись на реальной RTX 3050 Laptop GPU с 6 ГБ видеопамяти. Аппаратный ray tracing и DLSS не реализованы. Неоновые фонари используют излучающие материалы; динамическое ночное освещение и отдельные источники света от фонарей не добавлены.

Модели, фонари и материалы создаются кодом. Сторонние игровые ассеты, музыка и карта не добавлялись. Платные модели, API-ключи и платные сервисы разработки не используются.
