# Neon Frontier

Компактный оригинальный 3D-прототип открытого города на Rust 1.100+ и Bevy 0.20.1 для Windows 11. В проекте есть пешее управление, машина, трафик, жители, розыск, маршрутные задания и меню. Это не игра масштаба GTA 6.

## Текущее состояние

В `main` исправлен тест `sun_peaks_at_noon_and_bottoms_out_at_midnight`: `sun_height(1.5)` сравнивается с циклически эквивалентным `sun_height(0.5)`. Иерархия машины игрока исправлена: масштаб вынесен на отдельную деталь кузова, поэтому колёса и фары используют локальные координаты без дополнительного растяжения. Мигалки патрулей закреплены как дочерние детали и чередуются только при ненулевом уровне розыска.

В `src/city_life.rs` подключены некоторые OBB/SAT-проверки: трафик проверяет ориентированные кузова при объезде, машины трафика и игрока используют SAT-контакт с пешеходами. Остались круговые проверки и незакрытые пары столкновений; точный список ведётся в `TODO.md`. HUD разбивает длинные слова, включая длинные кириллические последовательности; тесты проверяют предел строки и сохранение символов, но размеры окна и масштаб интерфейса на Windows не проверены.

## Возможности в исходниках

- Камера от третьего лица, ходьба, бег, прыжок, разворот персонажа по движению и простая анимация.
- Управляемая машина: газ, тормоз, поворот, вход и выход; модель кузова, колёс и фар исправлена, но вид и поведение после актуального Windows-билда ещё нужно проверить.
- Процедурный компактный город с дорогами, тротуарами, зданиями, окнами и светом.
- 14 машин трафика, 14 жителей, две патрульные машины, пеший офицер и шесть уровней розыска.
- Мигалки прикреплены к патрульным машинам и мигают только при активном розыске.
- Маршрутные задания, кредиты и здоровье в HUD.
- PBR, HDR, тонмаппинг, bloom, туман, светящиеся окна и уличное освещение.
- Процедурные поверхности с зерном и бесшовным повтором; есть генерационные тесты.
- Меню: «Новая игра», «Загрузить сохранение», «Кредитс», «Сделано FoxVuk и Claude Opus 5.5».
- SAT/OBB используется в части контактов транспорта с пешеходами; полная система столкновений ещё не готова.
- Save V1 сохраняет игрока, машину и большую часть состояния города. Время мира пока не входит в снимок.

## Управление

- WASD — ходьба; в машине — газ, тормоз и поворот.
- Shift — бег; Space — прыжок; F — удар; E — сесть в машину или выйти при низкой скорости.
- Мышь — камера; Esc — пауза; B — bloom; F5/F9 — сохранить/загрузить в игре.
- В меню — стрелки вверх/вниз и Enter/пробел; пункты выбираются мышью.

## Сборка на Windows 11

Нужны Rust 1.100+, Cargo, MSVC C++ Build Tools и Windows SDK.

```powershell
cargo fmt --all -- --check
cargo test --release
cargo run --release
```

Аппаратные ray tracing и DLSS не реализованы; FPS на RTX 3050 не измерялся. Подробности и оставшиеся задачи — в `MUST_HAVE.md` и `TODO.md`.
