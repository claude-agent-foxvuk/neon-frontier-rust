# Neon Frontier

Оригинальный 3D-прототип городской игры на Rust для Windows 11. Это компактная ранняя версия с пешим перемещением, машиной, процедурным городом, простым трафиком и коротким маршрутом-миссией. Это не игра масштаба GTA 6 и не готовый AAA-релиз.

## Что уже есть

Сцена процедурно создаёт сетку дорог, разметку и здания разной высоты. Можно ходить пешком, сесть в одну машину, ездить и выйти при небольшой скорости. Есть базовые столкновения, камера от третьего лица с управлением мышью, маршрут из трёх точек с наградой, 14 машин простого трафика, 14 пешеходов, четыре крышных ориентира, 36 декоративных неоновых уличных фонарей и 9 цветных источников света на перекрёстках. В последнем коммите добавлено создание 1 008 оконных панелей на фасадах 36 зданий; этот код ещё не прошёл CI. F5 сохраняет игрока, машину, прогресс маршрута, кредиты и состояние bloom в `neon_frontier_save.txt` в текущей папке запуска; F9 загружает сохранение. Игровой процесс пока не проверен запуском на компьютере пользователя.

Windows CI run #14 успешно прошёл форматирование, 10 тестов, release-сборку и загрузку артефакта для коммита `3ff0da27a0e5ecb462716fc526630d4989952914`. Артефакт `neon-frontier-windows-x64` весит 28 561 276 байт и доступен до 2026-12-23 20:38:35 UTC. Это архив с `neon-frontier.exe`, не установщик. CI подтверждает компиляцию, но не запуск игры или её визуальную проверку. После run #14 добавлены фасадные окна; актуальный коммит ожидает отдельного Windows CI.

## Управление

- WASD — ходьба или газ/поворот машины.
- Shift — бег.
- Мышь — камера; первый щелчок ЛКМ захватывает курсор.
- E — сесть в машину рядом или выйти при малой скорости.
- Esc — пауза и освобождение мыши.
- B — переключить bloom.
- F5 — сохранить.
- F9 — загрузить.

Управление описывает код текущей версии; проверка ввода и камеры в запущенной игре ещё не проводилась.

## Сборка в Windows 11

Нужны Rust 1.100 или новее, Cargo, MSVC C++ Build Tools с компонентом Desktop development with C++ и Windows SDK. В PowerShell из папки проекта:

```powershell
rustup update stable
cargo test
cargo run --release
```

Первый запуск Cargo загрузит Bevy и зависимости и может занять время. CI проверяет форматирование, тесты, release-сборку и публикует артефакт `neon-frontier-windows-x64` на 30 дней. Run #14 успешно прошёл все шаги на коммите `3ff0da27a0e5ecb462716fc526630d4989952914`. Чтобы получить этот проверенный архив, открой GitHub Actions в приватном репозитории, выбери успешный run #14 «Windows build check» и скачай артефакт. Внутри находится `neon-frontier.exe`; это не установщик. Он не содержит более поздних фасадных окон.

Для локальной сборки установи Rust 1.100+ и MSVC Build Tools, затем выполни `cargo run --release`. Windows CI использует `opt-level = 2`, `lto = false`, `codegen-units = 16`, кэширует `~/.cargo/registry`, `~/.cargo/git` и `target`, а предел job равен 240 минутам.

## Графика и ограничения

В коде заданы PBR-материалы, HDR-камера, тонмаппинг, направленный свет с тенями и bloom. В городе есть девять цветных point lights без теней, а новый код добавляет излучающие окна. Производительность и качество не измерялись на реальной RTX 3050 Laptop GPU с 6 ГБ видеопамяти. Аппаратный ray tracing и DLSS не реализованы. Визуальный результат фасадных окон ещё предстоит проверить в запущенной игре.

Модели, окна, фонари и материалы создаются кодом. Сторонние игровые ассеты, музыка и карта не добавлялись. Платные модели, API-ключи и платные сервисы разработки не используются.
