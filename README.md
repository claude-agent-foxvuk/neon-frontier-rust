# Neon Frontier

Компактный процедурный 3D-прототип городской игры на Rust и Bevy для Windows 11. Сейчас есть пешее управление, прыжок, машина, городская сетка, миссия из трёх точек, меню, сохранение, трафик и пешеходы. Это ранний прототип, не игра масштаба GTA 6 и не готовый AAA-релиз.

## Что добавлено в текущем коде

- Пешеход блокируется припаркованной машиной игрока и машинами из ресурса дорожных тел; добавлены тесты радиусов своей машины.
- У NPC три условных очка здоровья: удар снимает одно, попадание машины смертельно. Убитый NPC перестаёт возвращаться к маршруту; добавлены тесты накопления урона и постоянного состояния смерти.
- Две патрульные машины получают цель игрока при розыске. Уровень розыска растёт после удара по пешеходу или наезда, ограничен пятью и постепенно спадает в спокойное время.
- На улицах добавлены приподнятые тротуары, бордюры и контрастные переходы у девяти центральных перекрёстков.
- HUD показывает уровень розыска.

Это описание исходников; сборка текущей версии ещё не проверена CI, а новые игровые эффекты требуют проверки свежего EXE.

## Управление

- WASD — ходьба или газ и поворот машины.
- Shift — бег.
- Space — прыжок.
- Мышь — камера; ЛКМ захватывает курсор.
- Enter или ЛКМ — начать из меню.
- E — сесть в машину рядом или выйти при малой скорости.
- F — удар по пешеходам.
- Esc — пауза и освобождение мыши.
- B — переключить bloom.
- F5 — сохранить; F9 — загрузить.

В меню оставлена надпись «Сделано FoxVuk и Claude Opus 5.5». Сохранение хранит позицию, машину, прогресс маршрута, кредиты и bloom в `neon_frontier_save.txt`.

## Сборка в Windows 11

Нужны Rust 1.100 или новее, Cargo, MSVC C++ Build Tools с компонентом Desktop development with C++ и Windows SDK. В PowerShell из каталога проекта:

```powershell
rustup update stable
cargo fmt --all -- --check
cargo test --release
cargo run --release
```

Первый запуск может долго скачивать Bevy и зависимости. GitHub Actions кэширует Cargo и `target`; прошлый тёплый запуск занял 3 мин 54 сек, холодная сборка может идти значительно дольше. `Cargo.lock` пока не закоммичен.

## Ограничения

Аппаратный ray tracing и DLSS не реализованы. FPS, температура и VRAM на RTX 3050 не измерялись. Физика уровня GTA 6 — ориентир, не обещание паритета. Геометрия города процедурная; чужие игровые ассеты, музыка и карты не добавлялись.
