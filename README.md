# Neon Frontier

Компактный процедурный 3D-прототип городской игры на Rust и Bevy для Windows 11. В проекте есть вид от третьего лица, ходьба, прыжок, машина, небольшая городская сетка, маршрут-миссия, трафик, жители и розыск. Это оригинальный ранний прототип, не игра масштаба GTA 6 и не готовый AAA-релиз.

## Что уже есть в коде

- Третье лицо, пешее движение, бег, прыжок и камера мышью. Персонаж поворачивается в сторону фактического движения и слегка покачивается при ходьбе; выразительная анимация шага и бега ещё открыта.
- Машина на WASD, вход рядом и выход при низкой скорости; физика пока упрощённая.
- Маршрут из трёх целей, кредиты за завершение, локальное сохранение, пауза и русский HUD.
- Процедурные дороги, здания, тротуары, бордюры, переходы, окна и городское освещение.
- 14 машин трафика, 14 жителей и две патрульные машины. Базовое торможение перед препятствиями есть; полноценный выбор свободной полосы и объезд пока требуется проверить и доработать.
- Удары по жителям, поля здоровья NPC и уровни розыска реализованы частично. Офицеры пока не выходят из машины и не стреляют.
- HDR, тонмаппинг, bloom, туман, PBR-материалы и процедурные текстуры. Последнее усиление текстур закоммичено, но ещё не прошло итоговую Windows-сборку и ручную визуальную проверку.

## Управление

- WASD — ходьба; за рулём — газ, тормоз и поворот.
- Shift — бег; Space — прыжок.
- Мышь — камера; ЛКМ захватывает курсор.
- Enter или ЛКМ — начать из меню.
- E — сесть в машину рядом или выйти при низкой скорости.
- F — удар по пешеходам.
- Esc — пауза и освобождение мыши; B — переключить bloom.
- F5 — сохранить; F9 — загрузить.

В главном меню указано: «Сделано FoxVuk и Claude Opus 5.5». Сохранение хранит позицию игрока и машины, прогресс маршрута, кредиты и bloom в `neon_frontier_save.txt`.

## Сборка в Windows 11

Нужны Rust 1.100 или новее, Cargo, MSVC C++ Build Tools с компонентом Desktop development with C++ и Windows SDK. Из каталога проекта:

```powershell
rustup update stable
cargo fmt --all -- --check
cargo test --release
cargo run --release
```

GitHub Actions кэширует Cargo и `target`. Run #37 восстанавливал кэш около 2 минут 26 секунд и завершился до тестов и компиляции из-за форматирования; это не замер времени сборки игры. Длительность следующей успешной сборки неизвестна.

## Ограничения

Аппаратный ray tracing и DLSS не реализованы. FPS, температура и VRAM на RTX 3050 не измерялись. Физика уровня GTA 6 — ориентир, не обещание полного паритета. Чужие игровые ассеты, музыка и карты не добавлялись.
