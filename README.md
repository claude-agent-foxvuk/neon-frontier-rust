# Neon Frontier

Компактная оригинальная 3D-игра с открытым городом на Rust 1.100+ и Bevy 0.20.1 для Windows 11. Это самостоятельный прототип с вождением и действием, не игра масштаба GTA 6.

## Уже есть
- Пешее управление, бег, прыжок, удар, здоровье и камера от третьего лица.
- Машина с инерцией, торможением, рулением и скольжением; трафик и жители.
- Процедурный компактный город с дорогами, фасадами, окнами и освещением.
- Шесть уровней розыска, две патрульные машины, пешие офицеры и мигалки.
- Русский HUD, маршрутные цели, кредиты, цикл дня и ночи, PBR, HDR, bloom и туман.
- Сохранение `NEON_FRONTIER_SAVE_V1`; главное меню с подписью «Сделано FoxVuk и Claude Opus 5.5».
- OBB/SAT используется в коллизиях игрока, машин, жителей, трафика, патрулей и зданий. Раздвижение пар машин учитывает живых пешеходов как неподвижные OBB-препятствия; новая live ECS-регрессия ожидает прогона #151.

## Управление
- WASD — ходьба; Shift — бег; Space — прыжок; F — удар.
- За рулём WASD — газ, тормоз и поворот; E — сесть или выйти при низкой скорости.
- Мышь — камера; Esc — пауза; B — bloom; F5/F9 — сохранить/загрузить во время игры.
- В меню — стрелки вверх/вниз, Enter/пробел или щелчок мыши.

## Сборка
На Windows 11 нужны Rust 1.100+, Cargo, MSVC C++ Build Tools и Windows SDK.

```powershell
cargo fmt --all -- --check
cargo test --release --features bevy/debug
cargo build --release --features bevy/debug
cargo run --release
```

Аппаратный ray tracing и DLSS не реализованы; FPS на RTX 3050 ещё не измерен.
