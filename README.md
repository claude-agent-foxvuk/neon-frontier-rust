# Neon Frontier

Компактный процедурный 3D-прототип городской игры на Rust и Bevy для Windows 11. В нём есть пешее управление, прыжок, машина, открытая городская сетка, маршрут-миссия, трафик, жители, патруль и розыск. Это ранний прототип, не игра масштаба GTA 6 и не готовый AAA-релиз.

## Последняя проверенная сборка

Windows run #33 завершился успешно на исходном коде SHA `0c783f62261dc68a7ad8f718b44cd133e867e8f0`. Все шаги прошли: `cargo fmt --all -- --check`, `cargo test --release`, `cargo build --release` и загрузка EXE. Артефакт `neon-frontier-windows-x64` весит 28 627 268 байт.

Прогон занял 5 мин 4 сек, шаг кэширования Cargo — 3 мин 25 сек. Это измерение одного запуска, а не обещание для следующих сборок. После run #33 в репозитории менялись только README, TODO и MUST_HAVE; исходный код игры не менялся.

Успешный CI подтверждает форматирование, тесты, компиляцию и создание EXE. Он не подтверждает запуск игры на ноутбуке Фокса, поведение столкновений или качество картинки. Отрицательный отзыв о сборке #29 ещё требует проверки актуального EXE в игре.

## Что есть в текущем исходном коде

- Третье лицо, ходьба, бег, прыжок, мышь для камеры, вход в машину и выход при малой скорости.
- Управление машиной на WASD, газ и торможение, простой поворот; масса, инерция и занос пока условные.
- Пеший игрок блокируется собственной припаркованной машиной и машинами трафика/патруля. Для коллизий используются радиусы; идущий персонаж и жители пока не имеют полноценного физического контакта.
- У NPC три условных очка здоровья: удар снимает одно, попадание машины наносит смертельный урон. Падение и сохранение состояния смерти покрыты unit-тестами.
- Пять уровней розыска, постепенное снижение уровня, две патрульные машины, которые преследуют игрока при активном розыске.
- Город из 36 зданий, 1 008 светящихся оконных деталей, 36 уличных световых стоек, цветной свет на девяти перекрёстках, тротуары, бордюры и переходы.
- Маршрут из трёх целей, кредиты за завершение, локальное сохранение, пауза и HUD на русском.
- PBR-материалы, HDR, тонмаппинг, bloom и атмосферный туман. Графика всё ещё ждёт оценки Фокса на свежем EXE.

## Управление

- WASD — ходьба; за рулём — газ, тормоз и поворот.
- Shift — бег; Space — прыжок.
- Мышь — камера; ЛКМ захватывает курсор.
- Enter или ЛКМ — начать из меню.
- E — сесть в машину рядом или выйти при малой скорости.
- F — удар по пешеходам.
- Esc — пауза и освобождение мыши; B — переключить bloom.
- F5 — сохранить; F9 — загрузить.

В меню оставлена надпись «Сделано FoxVuk и Claude Opus 5.5». Сохранение хранит позицию игрока и машины, прогресс маршрута, кредиты и bloom в `neon_frontier_save.txt`.

## Сборка в Windows 11

Нужны Rust 1.100 или новее, Cargo, MSVC C++ Build Tools с компонентом Desktop development with C++ и Windows SDK. Команды из каталога проекта:

```powershell
rustup update stable
cargo fmt --all -- --check
cargo test --release
cargo run --release
```

GitHub Actions кэширует Cargo и `target`. Тёплый прогон #33 занял 5 мин 4 сек, включая 3 мин 25 сек на кэширование. Следующая сборка может идти дольше. `Cargo.lock` пока не закоммичен.

## Ограничения

Аппаратный ray tracing и DLSS не реализованы. FPS, температура и VRAM на RTX 3050 не измерялись. Физика уровня GTA 6 — ориентир, не обещание паритета. Геометрия города процедурная; чужие игровые ассеты, музыка и карты не добавлялись.
