# Neon Frontier

Компактная процедурная 3D-игра на Rust и Bevy для Windows 11: небольшой город, пешее движение, машина, маршрутные задания, жители и розыск. Это оригинальный прототип, не игра масштаба GTA 6 или готовый AAA-релиз.

## Реализовано

- Вид от третьего лица; ходьба, бег, прыжок и камера мышью. Персонаж поворачивается по направлению движения, есть bob, покачивание шага и наклон при беге.
- Управляемая машина с газом, торможением, поворотом и простым заносом; вход и выход при низкой скорости.
- Повторяющийся маршрут из трёх точек, чередование маршрутов и кредиты.
- Процедурный город с дорогами, тротуарами, зданиями, окнами, светом и усиленными деталями процедурных текстур.
- Трафик прогнозирует препятствия и пробует объезд по соседней стороне; учитываются игрок, оставленная машина игрока и патрульные машины. Если обе стороны заблокированы, машина тормозит. Ориентированные кузова, восстановление потока и проверки после последних изменений остаются открытыми.
- Жители с базовым разделением тел, здоровьем, ударом, падением и реакцией на наезд.
- При розыске от двух звёзд активируется пеший офицер: преследование, видимая вспышка выстрела, урон и проверка прямой видимости через здания.
- Сохранение V1 записывает состояние игрока и машины, маршрут, кредиты, bloom, жителей, трафик, патрули, офицеров, здоровье и wanted stars с таймером. Кодек теперь записывает числа с девятью знаками после десятичной точки; добавлен тест round-trip точности, который ещё не запускался. Полное точное восстановление всего состояния остаётся открытым.
- В главном меню есть «Новая игра», «Загрузить сохранение» и «Кредитс», выбор с клавиатуры. F5/F9 обрабатываются только после старта игры. Выбор мышью ещё не добавлен.
- Устаревшая надпись «Маршрут выполнен» фильтруется в HUD; для неё есть регрессионный тест.
- HDR, тонмаппинг, bloom, туман, PBR-материалы, световые окна и уличное освещение.

## Управление

- WASD — ходьба; в машине — газ, тормоз и поворот.
- Shift — бег; Space — прыжок; F — удар.
- Мышь — камера; ЛКМ — захват курсора; Esc — пауза.
- Стрелки вверх/вниз или W/S, затем Enter/пробел — меню.
- E — сесть в машину рядом или выйти при низкой скорости.
- B — переключить bloom; F5 — сохранить; F9 — загрузить во время игры.

## Сборка в Windows 11

Нужны Rust 1.100 или новее, Cargo, MSVC C++ Build Tools с компонентом Desktop development with C++ и Windows SDK.

```powershell
rustup update stable
cargo fmt --all -- --check
cargo test --release
cargo run --release
```
