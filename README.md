# Neon Frontier

Компактный оригинальный 3D-прототип открытого города на Rust 1.100+ и Bevy 0.20.1 для Windows 11. Есть пешее управление, автомобиль, трафик, жители, розыск, маршрутные цели и меню. Это самостоятельный небольшой прототип, не игра масштаба GTA 6.

## Статус проверки

- Последний успешный Windows build check — #124 на игровом SHA `17302cc6c54792c175252b0e322b256a680cf4db`: format, ECS diagnostic release tests, release build, 10-секундный startup smoke и upload завершились успешно.
- Артефакт `neon-frontier-windows-x64` для #124 — 29 878 427 байт. Smoke запускался на Windows runner, не на ноутбуке Fox.
- В `main` добавлены две live ECS-регрессии: пересекающиеся пешеходы расходятся по OBB без розыска, а трафик останавливается перед OBB здания. Windows check для этих изменений ожидает результата.
- Ручной запуск EXE на Windows 11, кириллица и полный игровой цикл на ноутбуке Fox не подтверждены.

## Что уже есть

- Камера от третьего лица; ходьба, бег, прыжок, поворот персонажа, базовая анимация и удар.
- Машина с инерцией, торможением перед сменой направления, постепенным рулением и боковым скольжением.
- Процедурный компактный город с дорогами, тротуарами, фасадами, окнами и уличным освещением.
- Трафик, жители, две патрульные машины, шесть уровней розыска и пешие офицеры.
- Русский HUD, маршрутные цели, кредиты, здоровье, цикл дня и ночи, PBR, HDR, bloom и туман.
- Сейв остаётся `NEON_FRONTIER_SAVE_V1`; меню содержит подпись «Сделано FoxVuk и Claude Opus 5.5».
- OBB/SAT используется в части логики трафика, столкновений и ECS-сепарации. Полная интеграция остаётся открытой.

## Управление

- WASD — ходьба; за рулём — газ, тормоз и поворот.
- Shift — бег; Space — прыжок; F — удар; E — сесть в машину или выйти при низкой скорости.
- Мышь — камера; Esc — пауза; B — bloom; F5/F9 — сохранить/загрузить во время игры.
- В меню — стрелки вверх/вниз, Enter/пробел или щелчок мыши.

## Сборка на Windows 11

Нужны Rust 1.100+, Cargo, MSVC C++ Build Tools и Windows SDK.

```powershell
cargo fmt --all -- --check
cargo test --release --features bevy/debug
cargo build --release --features bevy/debug
cargo run --release
```

Аппаратный ray tracing и DLSS не реализованы; FPS на RTX 3050 не измерен. Открытые требования сгруппированы по приоритету в `TODO.md`, подтверждённые исходниками возможности — в `FEATURES.md`.
