# Neon Frontier

Компактный оригинальный 3D-прототип с открытым городом на Rust 1.100+ и Bevy 0.20.1 для Windows 11. Есть пешее управление, машина, трафик, жители, розыск, маршрутные задания и меню. Это не игра масштаба GTA 6.

## Возможности, присутствующие в исходниках

- Камера от третьего лица, ходьба, бег, прыжок, ориентация и анимация персонажа.
- Игровая машина с входом/выходом, рулением, разгоном, торможением и заносом.
- Процедурный компактный город с дорогами, тротуарами, зданиями, окнами и освещением.
- 14 машин трафика, 14 жителей, две патрульные машины, пеший офицер и шесть уровней розыска.
- Система маршрутных заданий, кредиты и здоровье в HUD.
- PBR-материалы, HDR, тонмаппинг, bloom, туман, процедурные поверхности с зерном и бесшовным повтором, дневное/ночное освещение.
- Главное меню: «Новая игра», «Загрузить сохранение», «Кредитс» и «Сделано FoxVuk и Claude Opus 5.5».
- Сериализатор сохранения V1 для состояния игрока, машины и значительной части города; открытые требования описаны в `TODO.md`.

Подробный перечень реализованного хранится в `MUST_HAVE.md`; оставшаяся работа сгруппирована по темам и приоритетам в `TODO.md`.

## Управление

- WASD — ходьба; в машине — газ, тормоз и поворот.
- Shift — бег; Space — прыжок; F — удар; E — сесть в машину или выйти при низкой скорости.
- Мышь — камера; Esc — пауза; B — bloom; F5/F9 — сохранить/загрузить внутри игры.
- В меню — стрелки вверх/вниз и Enter/пробел; пункты также выбираются мышью.

## Сборка на Windows 11

Нужны Rust 1.100+, Cargo, MSVC C++ Build Tools и Windows SDK.

```powershell
cargo fmt --all -- --check
cargo test --release
cargo run --release
```

Аппаратные ray tracing и DLSS не реализованы; FPS на RTX 3050 не измерялся. Полный перечень незавершённой работы — в `TODO.md`.
