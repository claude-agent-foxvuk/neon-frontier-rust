# Neon Frontier

Компактная процедурная 3D-игра на Rust и Bevy для Windows 11: небольшой город, пешее движение, машина, маршрут, жители и розыск. Это оригинальный прототип, не игра масштаба GTA 6 или готовый AAA-релиз.

## Статус Windows-сборки

Текущий `main` — `08e08aca9bf5506401ae13db27084d73bfbf1f29`. После SHA #41 добавлены три игровых коммита: анимация игрока, объезд трафика и пешая полиция. Они ещё не покрыты успешной Windows-сборкой. Нужен новый прогон на точном актуальном `main`. Успешный CI не заменяет ручной запуск игры на Windows 11.

## Реализовано

- Вид от третьего лица; ходьба, бег, прыжок и камера мышью. Персонаж плавно поворачивается по направлению движения; добавлены bob, покачивание шага и наклон при беге.
- Управляемая машина с газом, торможением и поворотом; вход и выход при низкой скорости.
- Маршрутная миссия из трёх точек, кредиты, пауза, bloom, русские подсказки и локальное сохранение.
- Процедурный город с дорогами, тротуарами, зданиями, окнами, светом и текстурами с усиленными деталями.
- Трафик с базовым торможением и выбором свободного бокового объезда; добавлены тесты выбора стороны и границ полосы.
- Жители с базовым разделением тел, здоровьем, ударом, падением и реакцией на наезд.
- При розыске от двух звёзд активируется пеший офицер; есть преследование, видимая вспышка выстрела, урон игроку и проверка прямой видимости через здания.
- HDR, тонмаппинг, bloom, туман и PBR-материалы.
- В главном меню есть строка «Сделано FoxVuk и Claude Opus 5.5».

## Управление

- WASD — ходьба; в машине — газ, тормоз и поворот.
- Shift — бег; Space — прыжок; F — удар.
- Мышь — камера; ЛКМ — захват курсора; Esc — пауза.
- Enter или ЛКМ — начать; E — сесть в машину рядом или выйти при низкой скорости.
- B — переключить bloom; F5 — сохранить; F9 — загрузить.

## Сборка в Windows 11

Нужны Rust 1.100 или новее, Cargo, MSVC C++ Build Tools с компонентом Desktop development with C++ и Windows SDK.

```powershell
rustup update stable
cargo fmt --all -- --check
cargo test --release
cargo run --release
```

## Ограничения

Физика уровня GTA 6 остаётся ориентиром, а не обещанием полного паритета. Аппаратный ray tracing и DLSS не реализованы; производительность на RTX 3050 отдельно не измерялась. Чужие игровые ассеты, музыка и карты не добавлялись.
