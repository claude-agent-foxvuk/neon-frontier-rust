# Neon Frontier

Оригинальный 3D-прототип городской игры на Rust для Windows 11. Это небольшой ранний прототип, а не игра масштаба GTA 6 и не готовый релиз.

## Прогресс по направлениям

Проценты оценивают объём реализованной части, а не качество или общую готовность игры. Наличие кода само по себе не подтверждает, что функция собирается или работает на компьютере. Результаты проверок отмечены отдельно.

## Что реализовано

Сцена процедурно создаёт дороги, разметку и здания разной высоты. Игрок может ходить пешком, сесть в машину, ездить и выйти при небольшой скорости. Есть базовые столкновения, третьеличная камера и маршрут из трёх точек с наградой. Дополнительный модуль создаёт 14 движущихся машин, 14 пешеходов и четыре светящихся ориентира. В последнем кодовом изменении транспорт и пешеходы разворачиваются по направлению движения; этот коммит пока не проверен Windows CI.

F5 сохраняет состояние игрока, машины, маршрута, кредитов и bloom в `neon_frontier_save.txt` в текущей папке запуска; F9 загружает его. Функцию ещё не проверяли в запущенной игре.

Это ранний прототип. В нём нет боевой системы, разнообразных заданий, проработанных районов, сложного трафика и полноценного меню настроек.

## Управление

- WASD — ходьба или газ/поворот машины.
- Shift — бег.
- E — сесть в машину рядом или выйти при малой скорости.
- Esc — пауза.
- B — переключить bloom.
- F5 — сохранить.
- F9 — загрузить.

Управление заложено в коде, но ещё не проверялось в запущенной сборке.

## Сборка в Windows 11

Нужны Rust 1.100 или новее, Cargo, MSVC C++ Build Tools с компонентом Desktop development with C++ и Windows SDK. Из папки проекта в PowerShell:

```powershell
rustup update stable
cargo test
cargo run --release
```

Первый запуск Cargo скачает Bevy и зависимости и может занять время. Windows workflow проверяет форматирование, выполняет тесты и release-сборку, затем загружает артефакт `neon-frontier-windows-x64` на 30 дней. Run #5 ещё проверял предыдущий коммит; после его завершения нужна отдельная проверка актуального `main`.

## Графика и ограничения

В коде заданы PBR-материалы, HDR-камера, тонмаппинг, направленный свет с тенями и bloom. Настройки и производительность не проверялись на реальной RTX 3050 Laptop GPU с 6 ГБ видеопамяти. Аппаратный ray tracing и DLSS не реализованы.

Модели и материалы генерируются кодом. Сторонние игровые ассеты, музыка и карта не добавлялись. Платные модели, API-ключи и платные сервисы разработки не используются.
