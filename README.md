# Neon Frontier

Оригинальный 3D-прототип городской игры на Rust для Windows 11. Это ранняя небольшая версия, не игра масштаба GTA 6 и пока не готовый релиз.

Наличие функции в коде само по себе не подтверждает успешную сборку, работу в игре или качество на реальном ПК. Статус проверки указан отдельно.

## Что уже заложено в проект

Город строится из простых процедурных геометрических форм: дороги, разметка и здания разной высоты. На четырёх зданиях в центральной части добавлены светящиеся ориентиры. Игрок перемещается пешком, может сесть в машину, вести её и выйти при небольшой скорости. Есть базовые столкновения со стенами зданий и границами карты, третьеличная камера и маршрут «Три маяка» из трёх точек с наградой за каждую. Дополнительный модуль добавляет машины, движущиеся вдоль дорог, и жителей, которые ходят по коротким маршрутам. Поведение транспорта и жителей упрощённое. F5/F9 сохраняют и восстанавливают часть игрового состояния в файле `neon_frontier_save.txt` в текущей папке запуска; поддержка сохранений есть в коде, но ещё не прошла Windows CI и запуск игры.

Это ранний каркас играбельного прототипа. В игре ещё нет боевой системы, разнообразных заданий, проработанных районов, сложного трафика и полноценного меню настроек. Загрузка игры и билд пока не проверены. Размер мира и графика далеки от GTA 6.

## Управление, заложенное в коде

- WASD — ходьба или газ и поворот машины.
- Shift — бег.
- E — сесть в машину рядом с ней или выйти при малой скорости.
- Esc — пауза.
- B — включить или выключить bloom.
- F5 — записать локальное сохранение.
- F9 — загрузить локальное сохранение.

Управление ещё нужно проверить в запущенной сборке.

## Сборка в Windows 11

Нужен Rust 1.100 или новее, Cargo, MSVC C++ Build Tools с компонентом Desktop development with C++ и Windows SDK. Из папки проекта в PowerShell:

```powershell
rustup update stable
cargo test
cargo run --release
```

Первый запуск Cargo скачает Bevy и зависимости и может собираться долго. Windows workflow проверяет форматирование, запускает `cargo test` и `cargo build --release`, затем при успехе публикует артефакт `neon-frontier-windows-x64` на 30 дней. Скачать его можно в разделе Artifacts успешного запуска GitHub Actions. Текущий run #5 ещё не завершён и относится к коммиту до добавления сохранений; чтобы проверить актуальный код, после него нужно запустить CI на свежем коммите.

## Графика и ограничения

Для картинки заданы PBR-материалы, HDR-камера, тонмаппинг, направленный свет с тенями и умеренный bloom. Их работа зависит от сборки и реального запуска. На ASUS TUF Gaming F16 с RTX 3050 Laptop GPU 6 ГБ игра ещё не проверялась; FPS, расход VRAM и визуальный результат неизвестны. Настройки качества и масштаба рендеринга ещё предстоит добавить. Аппаратный ray tracing и DLSS не реализованы.

Все модели и материалы сцены генерируются кодом; сторонние игровые ассеты, музыка и карта не добавлены. Платные модели и API-ключи в разработке не используются.
