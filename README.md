# Neon Frontier

Оригинальный компактный 3D-прототип городской игры на Rust для Windows 11. Сейчас есть пешее управление, одна управляемая машина, процедурный город, простой трафик, короткая маршрут-миссия, стартовое меню и сохранение. Это ранний прототип, не игра масштаба GTA 6 и не готовый AAA-релиз.

## Текущий статус

Фокс запускал старый EXE из run #18 на Windows 11 Pro, ASUS TUF Gaming F16 с RTX 3050 Laptop GPU 6 ГБ. Vulkan распознал видеокарту и Bevy создал окно, после чего приложение завершилось с Bevy `error[B0001]`. Игровой процесс не стартовал.

В код добавлены взаимоисключающие ECS-фильтры для запросов машин и пешеходов как кандидат на исправление `B0001`. Windows run #21 успешно прошёл форматирование, тесты, release-сборку и загрузку EXE на SHA `da4b4d2cf40e97da38e4991e8822c66ac694ec47`. Этот коммит включал предыдущий рефакторинг сохранений в `src/save.rs`; run подтверждает сборку и тесты, но не запуск на устройстве Фокса.

После run #21 меню и форматирование HUD выделены в `src/ui.rs`; подключение нового модуля в `src/main.rs` на SHA `eb45c27902efb5c6d3660140e2154cad0a364de4`. На момент этой записи новое разделение ещё не проходило Windows CI. Следующая проверка должна собирать актуальную версию с `ui.rs`.

## Что есть в коде

Процедурная городская сетка с дорогами, разметкой, 36 зданиями разной высоты, 14 машинами простого трафика, 14 пешеходами, четырьмя крышными ориентирами, 36 декоративными фонарями, девятью цветными источниками света и 1 008 светящимися окнами. Игрок может ходить и бегать, сесть в одну машину, ехать и выйти на малой скорости. Короткая миссия ведёт через три точки и выдаёт награду.

Главное меню содержит надпись «Сделано FoxVuk и Claude Opus 5.5». F5 сохраняет позицию игрока и машины, прогресс маршрута, кредиты и bloom в `neon_frontier_save.txt` в текущей папке запуска; F9 загружает сохранение. Формат и файловый ввод-вывод находятся в `src/save.rs`; экран начала и формирование HUD — в `src/ui.rs`.

## Управление

- WASD — ходьба или газ/поворот машины.
- Shift — бег.
- Мышь — камера; ЛКМ захватывает курсор.
- Enter или ЛКМ — начать из меню.
- E — сесть в машину рядом или выйти при малой скорости.
- Esc — пауза и освобождение мыши.
- B — переключить bloom.
- F5 — сохранить; F9 — загрузить.

## Сборка в Windows 11

Нужны Rust 1.100 или новее, Cargo, MSVC C++ Build Tools с компонентом Desktop development with C++ и Windows SDK. В PowerShell из каталога проекта:

```powershell
rustup update stable
cargo fmt --all -- --check
cargo test
cargo run --release
```

Первый запуск Cargo загружает Bevy и зависимости и может занять время. В workflow заданы `opt-level = 2`, `lto = false`, `codegen-units = 16`; кэшируются `~/.cargo/registry`, `~/.cargo/git` и `target`. Даже успешная компиляция не гарантирует запуск игры. Для актуальной версии скачай EXE-артефакт из самого свежего успешного Windows run.

## Графика, лицензии и ограничения

В коде заданы PBR-материалы, HDR-камера, тонмаппинг, направленный свет с тенями, bloom, светящиеся фасады и уличные огни. В логе старого запуска Vulkan распознал RTX 3050 Laptop GPU 6 ГБ, затем Bevy упал до игрового процесса. FPS, температура и VRAM не измерялись; визуальная оценка не проведена. Аппаратный ray tracing и DLSS не реализованы.

Модели, здания, окна, фонари и материалы создаются кодом. Сторонние игровые ассеты, музыка и чужая карта не добавлялись. Платные модели, API-ключи и платные сервисы разработки не использовались.
