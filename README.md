# Neon Frontier

Компактная процедурная 3D-игра на Rust 1.100+ и Bevy 0.20.1 для Windows 11: небольшой город, пешее движение, машина, маршрут, жители и розыск. Это оригинальный прототип, не игра масштаба GTA 6.

## Уже есть в исходниках
- Вид от третьего лица, ходьба, бег, прыжок, разворот по движению, bob и наклон.
- Машина игрока с газом, тормозом, поворотом, простым заносом, посадкой и выходом.
- Процедурный город, окна, уличный свет, PBR, HDR, bloom и туман.
- 14 машин трафика и 14 жителей; учитываются игрок, оставленная машина и патрули; трафик пробует боковой объезд.
- Два полицейских патруля; от двух звёзд пеший офицер преследует игрока, показывает вспышку и наносит урон при прямой видимости.
- V1-сейв записывает базовое состояние игрока, машины, маршрута, жителей, трафика, полиции и розыска. Точное восстановление полного мира остаётся открытым; V1 не менять.
- Меню с клавиатурными пунктами «Новая игра», «Загрузить сохранение» и «Кредитс». F5/F9 работают только в игре; мышиный выбор открыт.
- Устаревшее «Маршрут выполнен» фильтруется в HUD.

## Управление
- WASD — ходьба; в машине — газ, тормоз и поворот.
- Shift — бег; Space — прыжок; F — удар; E — войти в машину или выйти при низкой скорости.
- Мышь — камера; Esc — пауза; B — bloom; F5/F9 — сейв/загрузка внутри игры.
- Стрелки вверх/вниз и Enter/пробел — меню.

## Сборка для Windows 11
Нужны Rust 1.100+, Cargo, MSVC C++ Build Tools и Windows SDK.

```powershell
cargo fmt --all -- --check
cargo test --release
cargo run --release
```

Открытые требования и приоритеты — в `TODO.md`, функции, которые нужно сохранить, — в `MUST_HAVE.md`. Аппаратные ray tracing и DLSS не реализованы; производительность на RTX 3050 отдельно не измерялась.
