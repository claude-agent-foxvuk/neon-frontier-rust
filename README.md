# Neon Frontier

Компактная процедурная 3D-игра на Rust и Bevy для Windows 11: небольшой город, пешее движение, машина, маршрут, жители и розыск. Это оригинальный прототип, не игра масштаба GTA 6 или готовый AAA-релиз.

## Уже реализовано

- Вид от третьего лица; ходьба, бег, прыжок и камера мышью. Персонаж разворачивается по фактическому направлению движения, есть простое вертикальное покачивание.
- Управление машиной с газом, тормозом и заносом; вход и выход при низкой скорости.
- Маршрутная миссия из трёх точек, кредиты, пауза, bloom, русские подсказки и локальное сохранение.
- Процедурный город с дорогами, зданиями, тротуарами, бордюрами, окнами, светом и текстурами.
- 14 машин трафика, 14 жителей и две патрульные машины. Есть базовое торможение и скольжение вдоль части препятствий.
- Удар по жителям, здоровье NPC, сбивание с ног, наезд и уровни розыска; патрули преследуют игрока на машинах.
- HDR, тонмаппинг, bloom, туман, PBR-материалы и светящиеся городские детали.
- В главном меню есть строка «Сделано FoxVuk и Claude Opus 5.5».

## Управление

- WASD — ходьба; в машине — газ, тормоз и поворот.
- Shift — бег; Space — прыжок; F — удар.
- Мышь — камера; ЛКМ — захват курсора; Esc — пауза.
- Enter или ЛКМ — начать; E — сесть в машину рядом или выйти при низкой скорости.
- B — переключить bloom; F5 — сохранить; F9 — загрузить.

## Сборка в Windows 11

Нужны Rust 1.100 или новее, Cargo, MSVC C++ Build Tools с компонентом Desktop development with C++ и Windows SDK.

```powershell
rustup update stable
cargo fmt --all -- --check
cargo test --release
cargo run --release
```

## Ограничения

Физика уровня GTA 6 остаётся ориентиром, а не обещанием полного паритета. Аппаратный ray tracing и DLSS не реализованы; производительность на RTX 3050 отдельно не измерялась. Чужие игровые ассеты, музыка и карты не добавлялись.
