# Neon Frontier

Оригинальный 3D-прототип городской игры на Rust для Windows 11. Это небольшая ранняя версия, не игра масштаба GTA 6 и пока не готовый релиз.

## Прогресс

Проценты приблизительно оценивают код в каждом направлении отдельно. Они не означают общую готовность игры и не подтверждают, что код собрался или запустился. Код, который ещё не прошёл Windows-проверку, отмечен как непроверенный.

- Подготовка: [####################] 100% — приватный репозиторий, исходная идея и инструкция созданы.
- Игровая основа: [##########----------] 50% — пешее управление, машина, посадка и выход, столкновения со зданиями и границами, камера, HUD, пауза и переключатель bloom есть в коде; сборка и управление в игре пока не проверены, нет сохранений и полноценного меню настроек.
- Город и задачи: [##########----------] 50% — процедурная сетка улиц и 36 зданий, три контрольные точки с наградами, 14 движущихся машин и 14 простых прохожих описаны в коде; всё ожидает сборочной проверки, районы и сложное поведение жителей не сделаны.
- Графика: [########------------] 40% — материалы PBR, металлический кузов, HDR, тонмаппинг, тени и bloom настроены в коде; внешний вид, расход VRAM, качество на RTX 3050 и пресеты пока не проверены.
- Windows, тесты и получение сборки: [#####---------------] 25% — тесты логики и Windows workflow добавлены. Первая проверка GitHub Actions всё ещё выполняется для более раннего снимка кода; текущие изменения в неё не входят. Ни один результат теста пока не подтверждён, готового `.exe` или архива нет.

## Что уже заложено в проект

Город строится из простых процедурных геометрических форм: дороги, разметка и здания разной высоты. Игрок перемещается пешком, может сесть в машину, вести её и выйти при небольшой скорости. Есть базовые столкновения со стенами зданий и границами карты, третьеличная камера и маршрут «Три маяка» из трёх точек с наградой за каждую. Дополнительный модуль добавляет машины, движущиеся вдоль дорог, и жителей, которые ходят по коротким маршрутам. Поведение транспорта и жителей упрощённое.

Это пока каркас играбельного прототипа. В игре ещё нет полноценной боевой системы, разнообразных заданий, проработанных районов, сложного трафика, сохранения, меню настроек или готовой загрузки билда. Объём города и графики далёк от GTA 6.

## Управление, заложенное в коде

- WASD — ходьба или газ и поворот машины.
- Shift — бег.
- E — сесть в машину рядом с ней или выйти при малой скорости.
- Esc — пауза.
- B — включить или выключить bloom.

Управление ещё нужно проверить в запущенной сборке.

## Сборка в Windows 11

Нужен Rust 1.100 или новее, Cargo, MSVC C++ Build Tools с компонентом Desktop development with C++ и Windows SDK. Из папки проекта в PowerShell:

```powershell
rustup update stable
cargo test
cargo run --release
```

Первый запуск Cargo скачает Bevy и зависимости и может собираться долго. Обновлённый Windows workflow проверяет форматирование, запускает `cargo test` и `cargo build --release`, затем при успехе публикует артефакт `neon-frontier-windows-x64` на 30 дней. Скачать его можно из раздела Artifacts соответствующего успешного запуска GitHub Actions. Первая проверка всё ещё выполняется для более раннего снимка кода, поэтому актуального exe пока нет; после неё нужно запустить workflow для последней версии.

## Графика и ограничения

Для картинки заданы PBR-материалы, HDR-камера, тонмаппинг, направленный свет с тенями и умеренный bloom. Их работа зависит от сборки и реального запуска. На ASUS TUF Gaming F16 с RTX 3050 Laptop GPU 6 ГБ игра ещё не проверялась; FPS, расход VRAM и визуальный результат неизвестны. Настройки качества и масштаба рендеринга ещё предстоит добавить. Аппаратный ray tracing и DLSS не реализованы.

Все модели и материалы сцены генерируются кодом; сторонние игровые ассеты, музыка и карта не добавлены. Платные модели и API-ключи в разработке не используются.
