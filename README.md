# Neon Frontier

Компактная процедурная 3D-игра на Rust 1.100+ и Bevy 0.20.1 для Windows 11: небольшой город, пешее движение, машина, маршрут, жители и розыск. Это оригинальный прототип, не игра масштаба GTA 6.

## Уже есть в исходниках

- Вид от третьего лица, ходьба, бег, прыжок, поворот персонажа по движению, bob и наклон.
- Машина игрока с газом, торможением, поворотом, простым заносом, посадкой и выходом.
- Процедурный город, окна, уличный свет, PBR, HDR, bloom и туман.
- 14 машин трафика и 14 жителей; трафик учитывает игрока, оставленную машину и патрули, пробует боковой объезд и тормозит, если проезда нет.
- Два полицейских патруля; при розыске от двух звёзд пеший офицер преследует игрока, показывает вспышку и наносит урон при прямой видимости.
- V1-сейв записывает базовые состояния игрока, машины, маршрута, жителей, трафика, патрулей, офицеров и розыска. Точное восстановление полного состояния мира остаётся открытым; заголовок V1 менять нельзя.
- Главное меню с клавиатурным выбором: «Новая игра», «Загрузить сохранение», «Кредитс». F5/F9 обрабатываются только после старта игры. Выбор мышью и тесты переходов ещё открыты.
- Устаревшее «Маршрут выполнен» фильтруется в HUD.

## Управление

- WASD — ходьба; в машине — газ, тормоз и поворот.
- Shift — бег; Space — прыжок; F — удар; E — войти в машину или выйти при низкой скорости.
- Мышь — камера; Esc — пауза; B — bloom.
- Стрелки вверх/вниз, затем Enter или пробел — выбор в меню.
- F5 — сохранить, F9 — загрузить внутри игры.

## Сборка для Windows 11

Нужны Rust 1.100+, Cargo, MSVC C++ Build Tools с Desktop development with C++ и Windows SDK.

```powershell
cargo fmt --all -- --check
cargo test --release
cargo run --release
```

Полный список незакрытых задач по темам и приоритетам — в `TODO.md`; существующие функции, которые нужно сохранить, — в `MUST_HAVE.md`. Аппаратный ray tracing и DLSS не реализованы, производительность на RTX 3050 отдельно не измерялась.
