# Neon Frontier

Оригинальный 3D-прототип городской игры на Rust для Windows 11. Это компактная ранняя версия с пешим перемещением, машиной, процедурным городом, простым трафиком и коротким маршрутом-миссией. Это не игра масштаба GTA 6 и не готовый AAA-релиз.

## Текущий статус запуска

Фокс проверил EXE из Windows run #18 на Windows 11 Pro и ASUS TUF Gaming F16. Лог подтвердил, что Vulkan обнаружил NVIDIA GeForce RTX 3050 Laptop GPU с 6 ГБ и Bevy создал окно. Затем процесс завершился panic `error[B0001]` из-за конфликтующих ECS-запросов. Это была версия старого коммита `1a2b20837ddb211f59bed597611760d70ecea036`; её EXE не считать рабочей игрой.

В код добавлены взаимоисключающие фильтры для запросов машин и пешеходов как кандидат на исправление `B0001`. Windows run #19 на коммите `08ff479a2dc19c39ea2486823e455830e49e75b4` остановился раньше тестов и сборки: `cargo fmt --all -- --check` обнаружил форматировочные расхождения в `src/city_life.rs`. Форматирование исправлено коммитом `51e8ad39bdd93752cda0c8ff8ef06a5c79029d0e`. Новый Windows run для этого коммита ещё не завершён; свежего EXE с исправлением пока нет. Ошибка `B0001` не подтверждена как исправленная.

## Что уже есть

В коде есть процедурная сетка дорог, разметка и здания разной высоты. Стартовый экран содержит надпись «Сделано FoxVuk и Claude Opus 5.5»; Enter или щелчок мыши начинают игру. Можно ходить пешком, сесть в одну машину, ездить и выйти при небольшой скорости. Есть базовые столкновения, камера от третьего лица с управлением мышью, маршрут из трёх точек с наградой, 14 машин простого трафика, 14 пешеходов, четыре крышных ориентира, 36 декоративных неоновых уличных фонарей и 9 цветных источников света на перекрёстках. Процедурные фасады включают 1 008 светящихся окон на 36 зданиях. F5 сохраняет игрока, машину, прогресс маршрута, кредиты и состояние bloom в `neon_frontier_save.txt` в текущей папке запуска; F9 загружает сохранение.

На проверенной владельцем сборке run #18 игра не дошла до меню: после создания окна она завершилась с `B0001`. Поэтому ввод, камера, миссия, графика и меню в запущенной игре пока не подтверждены.

## Проверки и артефакты

Windows CI run #18 успешно прошёл форматирование, тесты, release-сборку и загрузку EXE для коммита `1a2b20837ddb211f59bed597611760d70ecea036`. Его артефакт `neon-frontier-windows-x64` весил 28 562 085 байт, но запущенный Фоксом EXE упал с `B0001`; это устаревший и неисправный билд.

Run #19 проверял коммит `08ff479a2dc19c39ea2486823e455830e49e75b4` и завершился ошибкой на `cargo fmt --all -- --check`. Тесты, release-сборка и загрузка EXE были пропущены. Форматировочные изменения теперь находятся в main-коммите `51e8ad39bdd93752cda0c8ff8ef06a5c79029d0e`. Для него пока нет подтверждённого Windows CI результата и свежего EXE-артефакта.

## Управление

- WASD — ходьба или газ/поворот машины.
- Shift — бег.
- Мышь — камера; первый щелчок ЛКМ захватывает курсор.
- E — сесть в машину рядом или выйти при малой скорости.
- Esc — пауза и освобождение мыши.
- B — переключить bloom.
- F5 — сохранить.
- F9 — загрузить.

На запуске run #18 это управление проверить не удалось: приложение упало до показа игры.

## Сборка в Windows 11

Нужны Rust 1.100 или новее, Cargo, MSVC C++ Build Tools с компонентом Desktop development with C++ и Windows SDK. В PowerShell из папки проекта:

```powershell
rustup update stable
cargo fmt --all -- --check
cargo test
cargo run --release
```

Первый запуск Cargo загрузит Bevy и зависимости и может занять время. Workflow использует `opt-level = 2`, `lto = false`, `codegen-units = 16`, кэширует `~/.cargo/registry`, `~/.cargo/git` и `target`, а предел job равен 240 минутам. Успешная компиляция не гарантирует, что игра дойдёт до главного меню: run #18 завершился `B0001` на компьютере Фокса. Следующий артефакт нужно проверить запуском, когда Windows CI пройдёт на актуальном main.

## Графика и ограничения

В коде заданы PBR-материалы, HDR-камера, тонмаппинг, направленный свет с тенями и bloom. В городе есть девять цветных point lights без теней и процедурные излучающие окна. На ASUS TUF Gaming F16 с Windows 11 Pro Vulkan обнаружил RTX 3050 Laptop GPU 6 ГБ, но приложение упало до игрового процесса. FPS, температура и расход VRAM не измерялись; визуальную оценку графики сделать не удалось. Аппаратный ray tracing и DLSS не реализованы.

Модели, окна, фонари и материалы создаются кодом. Сторонние игровые ассеты, музыка и карта не добавлялись. Платные модели, API-ключи и платные сервисы разработки не используются.
