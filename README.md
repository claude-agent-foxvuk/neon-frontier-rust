# Neon Frontier

Оригинальный компактный 3D-прототип городской игры на Rust для Windows 11. Сейчас есть пешее управление, одна управляемая машина, процедурный город, простой трафик, короткий маршрут, стартовое меню и локальное сохранение. Это ранний прототип, не игра масштаба GTA 6 и не готовый AAA-релиз.

## Почему сборка долгая

Workflow выполняет `cargo test`, затем отдельный `cargo build --release`. В `Cargo.toml` зависимости в dev-профиле собираются с `opt-level = 3`, а release использует отдельный профиль с `opt-level = 2`, `lto = false` и `codegen-units = 16`. Cargo хранит результаты разных профилей отдельно, поэтому release повторно компилирует зависимости для другого профиля. В live-логе тестовой стадии было видно разрешение 572 пакетов и последовательную компиляцию Bevy/wgpu. Workflow кэширует Cargo registry, git и `target`, но чтения не подтвердили, что для этого запуска был cache hit. Тесты уже заняли 43 мин 20 сек; на 07:53 UTC release-компиляция шла около семи минут и продолжалась. Последний наблюдаемый лог продвинулся до `wgpu-core`; данных для точного ETA нет. Общий предел job — 240 минут, это timeout, а не прогноз длительности.

## Что есть в коде

Процедурная городская сетка с дорогами и разметкой, 36 зданиями разной высоты, 14 машинами простого трафика, 14 пешеходами, четырьмя крышными ориентирами, 36 декоративными фонарями, девятью цветными источниками света и 1 008 светящимися окнами. Игрок может ходить и бегать, сесть в одну машину, ехать и выйти на малой скорости. Короткая миссия ведёт через три точки и выдаёт награду.

Главное меню содержит надпись «Сделано FoxVuk и Claude Opus 5.5». Для меню и HUD выбираются Segoe UI, Arial и sans-serif; отображение кириллицы после этой правки нужно проверить на Windows. F5 сохраняет позицию игрока и машины, прогресс маршрута, кредиты и bloom в `neon_frontier_save.txt` в папке запуска; F9 загружает сохранение.

## Управление

- WASD — ходьба или газ/поворот машины.
- Shift — бег.
- Мышь — камера; ЛКМ захватывает курсор.
- Enter или ЛКМ — начать из меню.
- E — сесть в машину рядом или выйти при малой скорости.
- Esc — пауза и освобождение мыши.
- B — переключить bloom.
- F5 — сохранить; F9 — загрузить.

## Сборка в Windows 11

Нужны Rust 1.100 или новее, Cargo, MSVC C++ Build Tools с компонентом Desktop development with C++ и Windows SDK. В PowerShell из каталога проекта:

```powershell
rustup update stable
cargo fmt --all -- --check
cargo test
cargo run --release
```

Первый запуск Cargo загрузит Bevy и зависимости и может занять время. В workflow кэшируются `~/.cargo/registry`, `~/.cargo/git` и `target`. Настройки release: `opt-level = 2`, `lto = false`, `codegen-units = 16`. Даже успешная компиляция не гарантирует запуск игры. Для тестирования исправления текста и графики нужен EXE, собранный для актуального игрового SHA.

## Графика, лицензии и ограничения

В коде заданы PBR-материалы, HDR-камера, тонмаппинг, направленный свет с тенями, bloom, светящиеся фасады и уличные огни. Новая палитра, детали, туман и системный шрифт пока не прошли визуальную проверку в игре. Аппаратный ray tracing и DLSS не реализованы. Модели, здания, окна, фонари и материалы создаются кодом; чужие игровые ассеты, музыка и карты не добавлялись. Платные модели, API-ключи и платные сервисы разработки не использовались.
