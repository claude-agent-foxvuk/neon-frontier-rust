# Neon Frontier

Компактная процедурная 3D-игра на Rust и Bevy для Windows 11: небольшой город, пешее движение, машина, маршрут, жители и розыск. Это оригинальный прототип, не игра масштаба GTA 6 или готовый AAA-релиз.

## Реализовано

- Вид от третьего лица; ходьба, бег, прыжок и камера мышью. Персонаж плавно поворачивается по направлению движения; добавлены bob, покачивание шага и наклон при беге.
- Управляемая машина с газом, торможением и поворотом; вход и выход при низкой скорости.
- Маршрутная миссия из трёх точек с повторяющимися целями, кредитами и паузой.
- Процедурный город с дорогами, тротуарами, зданиями, окнами, светом и текстурами с усиленными деталями.
- Трафик прогнозирует препятствия, выбирает боковой объезд и учитывает машину игрока как препятствие после выхода из неё. Геометрия коллизий пока в основном круговая; полиция, встречные блокировки, полноценная проверка тестов и ручная оценка остаются открытыми.
- Жители с базовым разделением тел, здоровьем, ударом, падением и реакцией на наезд.
- При розыске от двух звёзд активируется пеший офицер; есть преследование, видимая вспышка выстрела, урон игроку и проверка прямой видимости через здания.
- Устаревшая ветка «Маршрут выполнен» удалена из `main.rs`; HUD также скрывает такой текст в старых уведомлениях. Регрессионные тесты есть, но ещё не подтверждены проверкой после последних изменений.
- HDR, тонмаппинг, bloom, туман и PBR-материалы.
- В стартовом экране есть строка «Сделано FoxVuk и Claude Opus 5.5» и действие начала игры. Полноценные пункты «Новая игра», «Загрузить сохранение» и «Кредитс» ещё предстоит добавить; F5/F9 доступны только после входа в игру.

## Управление

- WASD — ходьба; в машине — газ, тормоз и поворот.
- Shift — бег; Space — прыжок; F — удар.
- Мышь — камера; ЛКМ — захват курсора; Esc — пауза.
- Enter или ЛКМ — начать; E — сесть в машину рядом или выйти при низкой скорости.
- B — переключить bloom; F5 — сохранить; F9 — загрузить.

## Сборка в Windows 11

Нужны Rust 1.100 или новее, Cargo, MSVC C++ Build Tools с компонентом Desktop development with C++ и Windows SDK.

```powershell
rustup update stable
cargo fmt --all -- --check
cargo test --release
cargo run --release
```

## Ограничения

Физика уровня GTA 6 остаётся ориентиром, а не обещанием полного паритета. Аппаратный ray tracing и DLSS не реализованы; производительность на RTX 3050 отдельно не измерялась. Полное сохранение людей, машин, полиции, розыска и изменяемого мира ещё не реализовано. Чужие игровые ассеты, музыка и карты не добавлялись.
