# Neon Frontier — план и достижения

Пожелания и результаты сгруппированы по темам и приоритетам. Обновлено: 2026-11-24, 10:10 UTC.

## Подтверждённые достижения

### Основа и игровой цикл
- [x] Приватный проект на Rust 1.100 и Bevy 0.20.1; код разложен по `main.rs`, `city_life.rs`, `save.rs` и `ui.rs`.
- [x] Процедурная городская сетка, вид от третьего лица, ходьба, бег, прыжок, управляемая машина, маршрут из трёх целей, пауза и локальное сохранение.
- [x] В меню есть надпись «Сделано FoxVuk и Claude Opus 5.5».

### Физика, NPC и патруль
- [x] Пешего персонажа блокируют собственная припаркованная машина и машины трафика/патруля; радиусы столкновений покрыты тестами.
- [x] У NPC три очка здоровья: удар снимает одно, попадание машины смертельно; погибший NPC не возвращается на маршрут. Есть unit-тесты здоровья и постоянного состояния смерти.
- [x] Дорожные машины реагируют на препятствия; пешеходы сбиваются с ног и получают импульс.
- [x] Пять уровней розыска, постепенное снижение уровня, две машины патруля и преследование игрока.

### Город и визуальные эффекты
- [x] Добавлены тротуары, бордюры, переходы у девяти перекрёстков, световые стойки, цветные огни и светящиеся окна зданий.
- [x] Есть PBR-материалы, HDR, тонмаппинг, bloom и атмосферный туман.
- [x] README и этот список отражают текущее состояние; выполненные пункты убраны из `MUST_HAVE.md`.

### Проверка сборки
- [x] Windows run #33 прошёл на SHA `0c783f62261dc68a7ad8f718b44cd133e867e8f0`: форматирование, `cargo test --release`, release-сборка и загрузка EXE завершились успешно.
