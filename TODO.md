## Причина долгого CI и план проверки

Run #25 занял 1 ч 23 мин 32 сек: `cargo test` — 43 мин 20 сек, release build — 30 мин 28 сек. До изменения workflow тестовая и release-компиляция использовали разные профили, что приводило к повторной сборке зависимостей. В run #26 кэш сработал, но восстановление 2.63 GB заняло 2 мин 53 сек; тестовый шаг остановился через несколько секунд из-за `--locked` без `Cargo.lock`. Эта попытка не показывает скорость успешной новой конфигурации.

Текущие команды workflow — `cargo test --release` и `cargo build --release`, обе без `--locked`. Ожидается повторное использование release-зависимостей; фактическое ускорение станет известно только по успешному новому run. Поскольку lock-файл не закоммичен, набор транзитивных зависимостей не зафиксирован между запусками.

«Физика и коллизии как в GTA 6» — ориентир пожелания, а не обещание паритета с GTA 6. Это оригинальный компактный прототип, не проект масштаба GTA 6 или AAA-релиз.
