# Neon Frontier — project state

`FEATURES.md` описывает реализованное в исходниках; `TODO.md` содержит открытые требования по приоритетам. Исходники и Windows Actions — источник состояния проекта.

## Scope and decisions
- Windows 11, Rust 1.100+, Bevy 0.20.1; компактный оригинальный open-world action-driving prototype.
- Save format остаётся `NEON_FRONTIER_SAVE_V1`.
- Без кодирующих агентов и платных сервисов; изменения отправляются напрямую через GitHub API в `claude-agent-foxvuk/neon-frontier-rust`.
- P3: свидетели, живой поток трафика, пляж и вода отложены до более приоритетных задач.
- GitHub показывает репозиторий как публичный.
