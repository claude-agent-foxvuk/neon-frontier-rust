# Neon Frontier — состояние проекта

## Scope и решения
- Самостоятельная компактная open-world action-driving игра для Windows 11 на Rust 1.100+ и Bevy 0.20.1.
- Репозиторий: `claude-agent-foxvuk/neon-frontier-rust`; изменения делаются напрямую через GitHub API без кодирующих агентов и платных сервисов.
- Формат сейвов остаётся `NEON_FRONTIER_SAVE_V1`; `MUST_HAVE.md` не создавать.
- Реализованные функции находятся в `FEATURES.md`, открытые игровые функции — в `TODO.md`, тесты и ручные проверки — в `CHECKS.md`, технический рефакторинг — в `ENGINEERING.md`.
