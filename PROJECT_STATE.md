# Neon Frontier — состояние проекта

## Scope и решения
- Самостоятельная компактная open-world action-driving игра для Windows 11 на Rust 1.100+ и Bevy 0.20.1.
- Репозиторий: `claude-agent-foxvuk/neon-frontier-rust`; изменения через GitHub API без кодирующих агентов и платных сервисов.
- Формат сейвов остаётся `NEON_FRONTIER_SAVE_V1`; `MUST_HAVE.md` не создавать.
- Реализованные функции — в `FEATURES.md`, игровые требования — в `TODO.md`, проверки — в `CHECKS.md`, инженерный рефакторинг — в `ENGINEERING.md`.

## Текущее состояние
- В `src/city_life.rs` пути из inline-модуля `base` разрешаются через три include-файла в `src/city_life/base/`, которые подключают реальные `helpers.rs`, `traffic_avoidance.rs` и `sim.rs` из `src/city_life/`. #199 подтвердил старый сбой на отсутствующем `src\city_life\base\helpers.rs`; Windows-проверка #200 на исправляющем коммите всё ещё шла при чтении.
- В центре города добавлены четыре небольшие площадки с деревьями и скамьями. Регрессия проверяет, что площадки расположены между границей дороги и зданий; Windows #201 на этом коде при чтении находился на checkout.
- Режимы F2 качества и производительности переключают тени солнца и bloom; отдельное состояние режима отделено от горячей клавиши B. Влияние на FPS не измерено.
- В городе подключены три события: уход от полиции, чистая езда у трафика и скоростная езда у машин. Unit-покрытие есть; интеграционные и ручные проверки событий остаются открытыми.
- Машины трафика разворачиваются внутрь города у всех четырёх границ; runtime-регрессия включена в Windows-проверки.
- Добавлены четыре резервные патрульные машины: от трёх до шести звёзд они появляются на городских постах и добавляются в OBB-препятствия игрока. Windows-проверка этого кода ещё не подтверждена.
- В `TODO.md` остаются 6 из 18 игровых требований: P3 — 6. Это прогресс игрового кода, не готовность релиза.
- Ручной запуск у Fox, кириллица на Windows 11 и FPS на RTX 3050 не подтверждены.
