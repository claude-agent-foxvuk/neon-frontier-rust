# Neon Frontier — состояние проекта

## Scope и решения
- Компактная open-world action-driving игра для Windows 11 на Rust 1.100+ и Bevy 0.20.1.
- Репозиторий `claude-agent-foxvuk/neon-frontier-rust`; коммиты выполняются напрямую через GitHub API без кодирующих агентов и платных сервисов.
- Формат сохранения остаётся `NEON_FRONTIER_SAVE_V1`; `MUST_HAVE.md` не создавать.
- Реализованные функции — `FEATURES.md`, игровые требования — `TODO.md`, проверки — `CHECKS.md`, инженерное разбиение — `ENGINEERING.md`.
