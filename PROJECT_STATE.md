- Компактная open-world action-driving игра для Windows 11 на Rust 1.100+ и Bevy 0.20.1.
- Репозиторий `claude-agent-foxvuk/neon-frontier-rust`; коммиты напрямую через GitHub API без кодирующих агентов и платных сервисов.
