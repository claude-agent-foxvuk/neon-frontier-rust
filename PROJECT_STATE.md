# Neon Frontier — состояние проекта

## Scope и решения
- Самостоятельная компактная open-world action-driving игра для Windows 11 на Rust 1.100+ и Bevy 0.20.1.
- Репозиторий: `claude-agent-foxvuk/neon-frontier-rust`; изменения через GitHub API без кодирующих агентов и платных сервисов.
- Формат сейвов остаётся `NEON_FRONTIER_SAVE_V1`; `MUST_HAVE.md` не создавать.
- Реализованные функции — в `FEATURES.md`, игровые требования — в `TODO.md`, проверки — в `CHECKS.md`, инженерный рефакторинг — в `ENGINEERING.md`.

## Текущее состояние
- Windows #205 на `930ce1ab9e4a9ad95d1ee19af470d91576253b0c` завершилась ошибкой: 172 теста прошли, два упали. Этап форматирования прошёл; release build, startup smoke и загрузка EXE пропущены. - В `src/city_life.rs` пути из inline-модуля `base` разрешаются через три include-файла в `src/city_life/base/`, которые подключают реальные `helpers.rs`, `traffic_avoidance.rs` и `sim.rs` из `src/city_life/`. #199 подтвердил старый сбой на отсутствующем `src\city_life\base\helpers.rs`; в #205 код компилировался и тесты запустились.
- В центре города добавлены четыре небольшие площадки с деревьями и скамьями. Регрессия их размещения прошла в #205; визуальная проверка остаётся открытой.
- Режимы F2 качества и производительности переключают тени солнца и bloom; отдельное состояние режима отделено от горячей клавиши B. Влияние на FPS не измерено.
- В городе подключены три события: уход от полиции, чистая езда у трафика и скоростная езда у машин. Один тест строки оставшегося времени упал в #205; интеграционные и ручные проверки событий остаются открытыми.
- Машины трафика разворачиваются внутрь города у всех четырёх границ; runtime-регрессия прошла в #205.
- Добавлены четыре резервные патрульные машины: от трёх до шести звёзд они появляются на городских постах и добавляются в OBB-препятствия игрока. Соответствующий unit-тест прошёл в #205, но полный Windows-прогон упал на других тестах.
- В `TODO.md` остаются 6 из 18 игровых требований: P3 — 6. Это прогресс игрового кода, не готовность релиза.
