# Neon Frontier — состояние проекта

## Scope и решения
- Самостоятельная компактная open-world action-driving игра для Windows 11 на Rust 1.100+ и Bevy 0.20.1.
- Репозиторий: `claude-agent-foxvuk/neon-frontier-rust`; изменения через GitHub API без кодирующих агентов и платных сервисов.
- Формат сейвов остаётся `NEON_FRONTIER_SAVE_V1`; `MUST_HAVE.md` не создавать.
- Реализованные функции — в `FEATURES.md`, игровые требования — в `TODO.md`, проверки — в `CHECKS.md`, инженерный рефакторинг — в `ENGINEERING.md`.

## Текущее состояние
- Режимы F2 качества и производительности переключают тени солнца и bloom; отдельное состояние режима отделено от горячей клавиши B. Windows-проверка на свежем коде ещё не завершена, влияние на FPS не измерено.
- В городе подключены три события: уход от полиции, чистая езда у трафика и скоростная езда у машин. Unit-покрытие есть; интеграционные и ручные проверки событий остаются открытыми.
- Машины трафика разворачиваются внутрь города у всех четырёх границ; runtime-регрессия включена в текущие Windows-проверки.
- Добавлены четыре резервные патрульные машины: от трёх до шести звёзд они последовательно появляются на городских постах и добавляются в OBB-препятствия игрока. Автоматическая регрессия написана, но ещё не прошла Windows-проверку.
- #193 для `f89d3c476dbd322bb201c1094c5124a8458230e6`: форматирование прошло, release-тесты шли в 06:37 UTC; сборка, startup smoke и артефакт не подтверждены. #192 и #191 на чтении также проходили release-тесты; #190, #189 и #188 отмечались выполняющимися без повторно прочитанных шагов.
- В `TODO.md` остаются 8 из 17 игровых требований: P3 — 8. Это прогресс игрового кода, не готовность релиза.
- Ручной запуск у Fox, кириллица на Windows 11 и FPS на RTX 3050 не подтверждены.
