# Neon Frontier — состояние проекта

## Scope и решения
- Самостоятельная компактная open-world action-driving игра для Windows 11 на Rust 1.100+ и Bevy 0.20.1.
- Репозиторий: `claude-agent-foxvuk/neon-frontier-rust`; изменения через GitHub API без кодирующих агентов и платных сервисов.
- Формат сейвов остаётся `NEON_FRONTIER_SAVE_V1`; `MUST_HAVE.md` не создавать.
- Реализованные функции — в `FEATURES.md`, игровые требования — в `TODO.md`, проверки — в `CHECKS.md`, инженерный рефакторинг — в `ENGINEERING.md`.

## Текущее состояние
- Система `F2` переключает режим качества и производительности: включает или отключает тени солнца и bloom. Проверка новой системы Windows-прогоном ещё не завершена; влияние на FPS не измерено.
- В городе подключены три события: уход от полиции, чистая езда у трафика и скоростная езда у машин. Unit-покрытие есть, но интеграционные и ручные проверки событий остаются открытыми.
- Машины трафика разворачиваются внутрь города у всех четырёх границ; runtime-регрессия включена в проверку на текущем игровом коммите.
- #187 завершился падением на `cargo fmt` из-за повторного префикса `city_life/` в `#[path]`; правка путей попала в #188. В #189 форматирование прошло, тесты выполнялись при последнем чтении; сборка, startup smoke и артефакт ещё не подтверждены.
- В `TODO.md` остаются 10 из 18 игровых требований: P3 — 10. Это счёт игровых функций, а не готовность релиза.
- Ручной запуск у Fox, кириллица на Windows 11 и FPS на RTX 3050 не подтверждены.
